From Neurons to Networks: The Basic Building Block

1. A Loose, Brain-Inspired Idea

Real brain cells (neurons) receive signals from other cells, and if enough signal builds up, they "fire" a signal onward. Decades ago, researchers borrowed this rough idea as inspiration for a piece of software — not to copy the brain exactly, but to build something that takes in several signals and decides what to pass on.

That's all an "artificial neuron" is: a small calculation, sitting on a computer, with no biology involved. Brian doesn't need to know anything about actual brain cells to understand it — the name is just a nod to where the idea started.

2. What's Inside One Artificial Neuron

Picture a neuron deciding whether to flag a sale as "worth restocking fast" for one of Rafiki Insights' retail clients. It looks at a few signals — say, how many units sold this week, how many days of stock are left, and how often the item was searched for on the client's shop app.

input 1 (units sold) → weight → ⎫
input 2 (days of stock left) → weight → ⎬ → sum it all up → simple rule → output
input 3 (times searched) → weight → ⎭

Each input gets its own weight — just a number that says how much that particular input should matter. A weight is not fixed forever; it is a dial the network can turn up or down. The neuron adds up all the weighted inputs, then runs the total through a simple rule (for example, "if the total passes a certain point, output a strong signal; otherwise output a weak one") to produce one output number.

3. Stacking Neurons Into Layers, and Layers Into a Network

One neuron on its own can only notice one simple pattern. The real power comes from using many neurons side by side, arranged in layers:

  • Input layer — where the raw signals enter (units sold, stock left, searches, and so on)
  • Hidden layer(s) — layers of neurons in between, each one combining the outputs of the previous layer into new, slightly more useful signals
  • Output layer — the final neuron(s) that produce the answer we actually care about, like "restock urgently: yes/no"

The output of every neuron in one layer becomes an input into the neurons in the next layer. Stack enough of these layers together, each combining what came before, and the whole structure — a neural network — can pick up on far richer combinations of signals than any single neuron could alone.

Key Point. One neuron = weighted inputs, summed up, passed through a simple rule. A network is just many of these neurons wired together in layers, each layer building on the last.
