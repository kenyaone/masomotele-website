What Deep Learning Adds Over Simple Models

1. What "Deep" Actually Means

Back in Topic 1, a network was described as an input layer, one or more hidden layers, and an output layer. A "deep" network is simply one with many hidden layers stacked on top of each other — sometimes dozens or more — rather than just one or two.

That's the entire meaning of the word "deep" here. It is not a claim about the network being smarter in some mysterious sense, or thinking deeply about anything — it is purely a description of how many layers are stacked between the input and the output.

2. Hand-Crafted Features vs Features the Network Discovers Itself

Older, simpler machine-learning models usually need a person to first decide which "features" — specific signals — are worth feeding in. For a simple loan-risk model, a Rafiki Insights analyst might hand-pick features like "average monthly deposit" or "number of missed repayments" before the model ever sees the data.

Simple modelAn analyst hand-picks the useful signals in advance; the model only ever sees those chosen features.
Deep networkEarly layers pick up simple raw patterns; later layers combine those into increasingly abstract, useful signals — largely on their own, with far less need for a person to hand-pick features first.

This is one of the biggest practical differences: a deep network can often work from rawer data and build its own useful internal features layer by layer, rather than depending entirely on a person's judgment about what matters.

3. The Trade-Off: Data and Computing Power

This benefit comes at a cost. Learning good features from scratch, layer by layer, generally requires far more example data and far more computing power than a simpler model that only has to learn a much smaller, hand-picked set of features.

If a Rafiki Insights client only has a few hundred sales records, a deep network may not have nearly enough examples to learn reliable features on its own — a simpler model, using a handful of sensible hand-picked signals, can often perform just as well, train much faster, and cost far less to run.

Key Point. "Deep" just means many stacked layers. That depth lets a network learn increasingly abstract features on its own instead of relying on hand-crafted ones — but it typically demands much more data and computing power to pay off.
