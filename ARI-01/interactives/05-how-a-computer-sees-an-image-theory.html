How a Computer 'Sees' an Image

A Picture Is Really Just Numbers

When Brian, a junior analyst at Rafiki Insights in Eldoret, opens a photo on his laptop, he sees a shopfront, a face, or a number plate. The computer never sees any of that. It only sees a grid of tiny squares called pixels, and every single pixel is stored as a number (or a small set of numbers for colour: one each for red, green and blue, usually from 0 to 255).

A small black-and-white photo might be a grid of, say, 100 rows by 100 columns — 10,000 numbers in total, each one saying "how bright is this exact spot." A colour photo is the same idea, just with three numbers per pixel instead of one. Zoom in far enough on any digital photo and this is exactly what you would find: a mosaic of numeric values, nothing more.

Looking for Patterns, Not "Seeing" Like a Person

Because all a computer vision system has to work with is this grid of numbers, it cannot "recognise" a car the way a human instantly does. Instead, it looks for mathematical patterns in how those numbers change across the grid: a sudden jump in brightness between neighbouring pixels usually marks an edge (like the outline of a number plate against a car bumper); a cluster of similarly-coloured pixels might form a shape (like a rectangle); and combinations of edges and shapes can be matched against patterns the system has learned before.

This is why a computer vision tool can be confused by things a person would never be confused by — a photo taken in low light, at a strange angle, or with something partly blocking the object — because those situations change the numbers in ways that no longer match the patterns it expects.

Key Point. A computer vision system does not "see" a scene — it processes a grid of pixel numbers, hunting for edges, shapes and patterns in that grid. Everything else (recognising a number plate, a face, a product) is built on top of this basic numeric view.

From Pixels to Meaning

On its own, a single pixel value tells you almost nothing. It is only when thousands of pixel values are looked at together — where the edges are, how they connect into shapes, how those shapes are arranged — that a computer vision system can start producing something useful: "this looks like a number plate," or "this looks like a gap on a shelf." Every computer vision task Brian will meet in later lessons, from simple classification to full object detection, starts from exactly this same numeric grid.
