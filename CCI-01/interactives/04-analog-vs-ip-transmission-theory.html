Analog vs IP Transmission

Two Ways Video Gets From Camera to Recorder

An analog camera sends its video as a continuous analog signal down a coaxial cable (usually RG59 with BNC connectors) straight into a DVR (Digital Video Recorder), which digitizes and stores it. An IP camera does the digitizing itself, then sends the video as data over an Ethernet cable into an NVR (Network Video Recorder), the same way a computer sends data over a network.

Dennis sees both types of job at SafeView Security Systems: older shops with coax already run through the ceiling, and new offices with nothing installed yet.

Cable, Distance, and Power Differences

Analog cameras usually need a separate power cable run alongside the coax, unless a combo cable is used. IP cameras commonly use PoE (Power over Ethernet), which carries both power and data down one Cat5e/Cat6 cable, simplifying the install considerably. The trade-off is distance: a standard PoE/Ethernet run is generally limited to about 100 metres per segment before a switch or extender is needed, while coax can often run a bit further before the analog signal starts to degrade.

Key Point. Before quoting a job, check what cable is already in the walls — reusing existing coax with an HD-analog upgrade is often the cheapest option, while a bare building with no wiring is usually a clean fit for IP over Cat6.

Choosing Based on the Client's Building

If a client already has coax wiring in place, upgrading to modern HD-analog cameras (which now reach several megapixels) and a matching DVR keeps costs down and avoids tearing open walls or ceilings. If the building is new or has no camera cabling at all, running Cat6 for IP/PoE cameras usually makes more sense, especially when the client wants higher resolution, remote viewing, or smart analytics features.

When a client wants to add new IP cameras onto an existing analog system without abandoning the old coax, a hybrid DVR — one that accepts both analog and IP camera inputs — lets Dennis combine both on a single recorder.
