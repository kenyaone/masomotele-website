1. The CPU in plain terms

The CPU (Central Processing Unit) executes instructions. Three specs matter most day-to-day: core count (how many independent tasks it can truly run in parallel), clock speed (how many cycles per second each core runs, in GHz), and cache (small, extremely fast on-chip memory that avoids slower trips to RAM for frequently used data).

2. RAM basics

RAM (Random Access Memory) is volatile, high-speed working memory — everything currently open and in-use lives here, and it's wiped on shutdown. Two RAM sticks of matching speed installed in the correctly paired slots run in dual-channel mode, roughly doubling memory bandwidth compared to a single stick of the same total capacity — this is a real, measurable performance difference, not a marketing claim.

Common mistake: mixing RAM sticks of different speeds. The system will run, but every stick is forced down to the speed of the slowest one.

4. Why thermal paste matters

Even a perfectly flat metal cooler base has microscopic gaps and imperfections against the CPU's surface — air trapped in those gaps insulates heat rather than conducting it. Thermal paste fills those microscopic gaps, dramatically improving heat transfer from CPU to cooler. Paste that has dried out (common after 2–5 years) loses effectiveness and causes rising temperatures even with an otherwise healthy cooler — this is one of the most common, easily-fixed causes of an "overheating" complaint Peter sees.
