Diagnostic Software and Tools

1. Built-in Windows tools

ToolWhat it checks
Windows Memory DiagnosticRuns a RAM test on reboot, flags memory errors
Event ViewerLogs of system errors, crashes and warnings -- often shows exactly when and why something failed
Task Manager and Resource MonitorLive CPU, RAM, disk and network usage -- spotting a runaway process or maxed-out resource
chkdskScans a drive file system for errors and, optionally, bad sectors

2. Third-party tools Peter relies on

  • Stress-testing software -- deliberately loads the CPU or GPU to near-100 percent to reveal instability or thermal throttling that light everyday use would not expose
  • Hardware monitoring software -- real-time temperatures, voltages and fan speeds, invaluable for confirming or ruling out a heat-related theory
  • Memory testing tools -- more thorough, longer-running RAM tests than the built-in Windows one

3. SMART data

Modern drives track their own health via S.M.A.R.T. (Self-Monitoring, Analysis and Reporting Technology) -- attributes like reallocated sector count, power-on hours, and read error rate. A drive reporting SMART warnings is telling you it is failing, often before a customer notices any symptoms -- checking SMART status proactively is one of the highest-value quick checks Peter runs on almost every job.

Peter habit: he checks SMART status on every single machine that comes in, regardless of the reported complaint -- it takes 30 seconds and can catch a drive that is about to fail before it becomes a data-loss emergency.

4. The limits of software diagnostics

Software tools can only report what the hardware itself is willing and able to report. A dead PSU rail, a physically cracked solder joint, or a component that fails intermittently under specific conditions software cannot easily replicate -- these often need physical inspection or hardware-level swap-testing, not just software.
