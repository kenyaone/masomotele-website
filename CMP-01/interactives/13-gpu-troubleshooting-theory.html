GPU Troubleshooting

Physical practicum required. This step teaches the judgement and correct sequence for a real hands-on repair task. To be certified competent in the physical technique itself (not just the decision-making), you must complete a supervised in-person practicum session — this online step alone does not certify hands-on ability.

1. Visual artifacts

Screen tearing, coloured static, flickering textures, or strange geometric glitches while otherwise using the system normally are classic signs of a GPU (or occasionally a driver) problem, distinct from a simple no-display fault. If artifacts appear even on the BIOS screen, before any driver has loaded, this points strongly at a hardware GPU fault rather than software.

2. Isolating GPU vs monitor vs driver

TestWhat it tells you
Swap in a known-working monitor and cableRules the monitor and cable in or out
Test with the motherboard onboard graphics, if available, GPU removedIf artifacts disappear, the fault is in the GPU, not the motherboard or monitor
Boot into Safe Mode, which uses a basic driverIf artifacts disappear in Safe Mode, a corrupted or incompatible driver is a likely cause, not necessarily hardware

3. Power delivery to the GPU

Higher-end GPUs need dedicated 6-pin or 8-pin power connectors direct from the PSU, separate from the motherboard slot power. A GPU that is detected but crashes or artifacts only under gaming load, while working fine on the desktop, often points to insufficient or unstable power delivery rather than a dead GPU.

Always check that every required PCIe power connector is actually plugged in -- a partially connected GPU is a surprisingly common real-world cause of exactly this symptom.

4. Driver crashes vs true hardware failure

A GPU driver crash typically shows as the screen going black briefly, then a notification that the display driver recovered, with the system otherwise continuing to run. True hardware failure is generally more consistent and severe: persistent artifacts, crashes that require a hard reboot, or total failure to output any signal at all.
