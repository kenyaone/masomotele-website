Accessing and Navigating BIOS/UEFI

1. Entering BIOS/UEFI

Most systems display a brief prompt during startup, such as "Press DEL to enter Setup" or "Press F2 for BIOS". The exact key varies by manufacturer: DEL and F2 are common on desktops, while F2, F10 or F12 are common on laptops. Timing matters -- the window to press the key is brief, right after power-on and before the OS begins loading.

2. The main BIOS/UEFI sections

SectionWhat it is used for
MainBasic system information: date, time, installed CPU and RAM summary
AdvancedDetailed hardware configuration: onboard devices, virtualization settings, fan curves
BootBoot order (which drive or device to try first), enabling boot from USB
SecurityBIOS password, Secure Boot toggle, TPM settings
ExitSave changes and restart, discard changes, or load default settings

3. Why this matters for a technician

Enabling boot from a USB installer, correcting a boot order after a drive swap, checking whether virtualization is enabled, or simply confirming installed RAM is actually detected correctly -- all of this happens in BIOS/UEFI, before the operating system is even involved. Confident BIOS navigation is a foundational skill underneath almost every other repair task in this course.

4. Practise it in the simulation

The Practical for this topic is a click-through simulation of a typical BIOS/UEFI menu system. Practise navigating to the right section for a given task -- there is no real risk of changing settings on an actual machine while you build this muscle memory.
