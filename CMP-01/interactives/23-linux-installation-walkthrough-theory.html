Linux Installation Walkthrough

1. When Linux makes sense

Linux is a genuinely good recommendation for an older machine with modest hardware, struggling to run a current version of Windows comfortably, especially if the customer mainly uses a web browser, email and basic office tools. It is also relevant for customers who want to avoid Windows licensing costs on a rebuild, or specifically want an open-source system.

2. Key decision points during install

  • Choosing "Try" mode first, to confirm the hardware works well before committing to installation
  • Selecting installation type: erase the entire disk for a clean single-OS setup, or install alongside an existing OS for dual-boot
  • Setting up disk partitions, or accepting the sensible guided defaults if unsure
  • Creating the initial user account and password

3. Dual-boot considerations

Installing Linux alongside an existing Windows installation, rather than replacing it, requires care with partitioning and, as covered earlier in this unit, sometimes requires adjusting Secure Boot settings. A boot manager screen, letting the user choose which OS to start, typically appears automatically after a successful dual-boot install.

Always confirm a backup exists before any dual-boot partitioning work -- resizing an existing Windows partition to make room carries real risk if interrupted or done incorrectly.

4. Checking hardware compatibility first

Before committing to an install, especially on laptops, checking Wi-Fi, graphics, and trackpad compatibility with the target Linux distribution avoids an unpleasant surprise after installation is already complete. The "Try" mode mentioned earlier is exactly for catching this in advance.
