Networking Basics and Wi-Fi Setup

1. Router vs modem

A modem connects the home to the internet service provider's network. A router creates the local home network and shares that internet connection across multiple devices, both wired and wireless. Many home setups combine both functions into a single combo device, but understanding them as separate functions helps when diagnosing exactly where a problem sits.

2. Setting up and securing Wi-Fi

  • Change the default admin password on the router itself -- leaving it at the factory default is a real security risk
  • Use WPA2 or WPA3 encryption, never the outdated and insecure WEP
  • Choose a strong, unique Wi-Fi password, separate from the router's admin password
  • Consider a separate guest network for visitors, keeping them off the main home network

3. Diagnosing "no internet" systematically

  1. Confirm whether it affects one device or every device on the network
  2. Check physical cable connections and router/modem lights for anything obviously wrong
  3. Restart the modem and router, unplugging both for about 30 seconds -- this resolves a genuinely large share of everyday connectivity issues
  4. Check if the issue is a true internet outage from the provider, versus purely a local network or device problem

4. Wi-Fi signal issues

Weak or dropping Wi-Fi is often caused by distance, physical obstructions like walls, or interference from other nearby networks and devices. Simple fixes include repositioning the router to a more central, open location, switching to a less congested Wi-Fi channel, or adding a mesh system or extender for larger homes.
