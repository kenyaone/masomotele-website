Formatting Text

Select First, Then Format

Word only formats text that is selected (highlighted). Double-click selects a word, triple-click selects a paragraph, and click-drag selects a custom range. Formatting applied with nothing selected only affects text you type next.

Key Point. If a formatting button seems to "not work", check whether you actually selected text first.

Bold, Italic, Underline — With Purpose

Bold draws the eye to something important (a price, a deadline). Italic is for emphasis or titles. Underline is mostly reserved for links or headings in older document styles. Using all three on the same word looks cluttered — pick one per emphasis.

Brenda bolds prices on the Amani Stationers price list so customers can scan it quickly.

Alignment and Colour

Left align is the default for body text (easiest to read). Centre suits headings and shop notices. Justify stretches each line to fill the width — common in printed brochures. Font colour should stay high-contrast against the background; red text on white is readable, yellow is not.

Key Point. Consistency matters more than variety — pick one heading style and one body style, and reuse them throughout the document.
