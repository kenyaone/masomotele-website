Headers, Footers and Page Numbers

Headers and Footers

Insert → Header/Footer adds an editable strip at the top or bottom of every page automatically. Double-clicking near the top or bottom margin of any page also opens header/footer editing directly.

Key Point. Whatever you type in a header/footer repeats on every page without retyping it — ideal for a shop name or contact line.

Automatic Page Numbers

Insert → Page Number places an automatically-updating number (bottom-centre is the most common choice for a catalogue). Because it is automatic, it stays correct even if pages are added or removed later — unlike typing "Page 3" manually.

Different First Page

The Different First Page option (in the header/footer design tools) lets a cover page stay clean, with the header/footer only appearing from page 2 onward — useful for a catalogue whose first page is just the shop logo and title.

Key Point. Double-click anywhere in the normal document body to leave header/footer editing mode and return to typing.
