Images and Page Layout

Inserting and Wrapping Images

Insert → Pictures places an image at the cursor. By default it is In Line with Text — it behaves like a giant character, pushing text down. To let text flow around it, use Wrap Text → Square (text forms a box around the image) or Behind Text (image sits behind, useful for a watermark-style logo).

Key Point. If an image "won't move" where you drag it, it is still set to In Line — change the wrap option first.

Resizing Without Distortion

Dragging a corner handle resizes an image proportionally (width and height scale together). Dragging a side handle stretches only one dimension, distorting the image — avoid this for logos and photos.

Margins, Orientation and Page Size

Layout → Margins controls the blank border around the page (Normal is usually 2.54cm on each side). Orientation is Portrait (tall, default for letters) or Landscape (wide, better for a table with many columns). Page size for Kenya is usually A4 — check this matches what the shop's printer expects before printing many copies.

Key Point. Always check margins and orientation before printing a large batch — one wrong setting wastes a whole ream of paper.
