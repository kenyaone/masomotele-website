Lists and Tables

Bulleted vs Numbered Lists

Use a numbered list when order matters — steps in a process, ranked items. Use a bulleted list when items are equally important with no required order — a list of products, a list of supplies needed.

Nested Lists

Pressing Tab at the start of a list line indents it one level deeper, creating a sub-list (e.g. "Stationery" with sub-items "Pens", "Pencils", "Rulers" underneath). Shift+Tab moves it back out a level.

Key Point. Nested lists work well for a stock list organised by category.

Tables

Insert → Table lets you choose rows and columns visually. Once inserted, click inside any cell to type; press Tab to jump to the next cell (and Tab in the last cell of a row creates a new row automatically). Right-click gives options to insert/delete rows and columns, and Merge Cells combines several cells into one — useful for a table title spanning the top row.

Key Point. Tab in the very last cell of a table creates a brand new row — useful, but easy to trigger by accident.
