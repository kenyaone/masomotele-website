Module 1 · Lesson 1.6

Mail Merge

What Mail Merge Solves

Mail Merge combines one main document (a letter with placeholders) with a data source (a list of names/addresses, often an Excel sheet) to produce one personalised copy per row of data — e.g. 40 wholesale customers each getting a letter addressed to them by name.

Key Point. Without Mail Merge, personalising 40 letters means editing and printing 40 separate documents by hand.

The Two Ingredients

The main document is a normal Word letter with gaps like "Dear ___". The data source is a table of the details that fill those gaps — one row per recipient, one column per field (Name, Address, Amount Owed, etc.). Mailings → Select Recipients connects the data source to the document.

Merge Fields and Finishing

Mailings → Insert Merge Field places a placeholder like «Name» wherever you want that column's data to appear. Preview Results shows what each individual letter will actually look like before printing. Finish & Merge either creates one combined document with every personalised letter, or sends them straight to the printer.

Key Point. Always Preview Results before finishing a merge — it is much easier to catch a wrong column now than after 40 copies are printed.
