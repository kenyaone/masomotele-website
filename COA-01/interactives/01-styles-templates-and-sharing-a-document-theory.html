Styles, Templates and Sharing a Document

Styles vs Manual Formatting

A Style (Home tab, Styles gallery) is a saved bundle of formatting — font, size, colour, spacing — applied with one click. Manually formatting each heading by hand means if Brenda later wants all headings a different colour, she must re-edit every single one; updating a Style once updates every place it is used.

Key Point. If you find yourself formatting the same kind of text (e.g. every section heading) the same way more than twice, it should be a Style, not manual formatting.

Templates

Save As → Word Template (.dotx) turns a finished layout (say, the Amani Stationers invoice layout with logo, table, and footer already placed) into a reusable starting point. Opening a template creates a new, untitled document with that layout already in place, leaving the original template file unchanged.

Sharing as PDF

A .docx file can look different on someone else's computer if they lack the same fonts installed, and it is easy for a recipient to accidentally edit it. Saving/exporting as PDF (File → Save As → choose PDF, or File → Export) locks the exact appearance and is the standard way to send a finished invoice or quotation to a customer.

Key Point. Once a document is finished and ready to send to a customer, PDF is almost always the right format — not .docx.
