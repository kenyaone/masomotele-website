Absolute vs Relative References

Relative References

By default, a reference like B2 is relative — copying a formula from row 2 to row 3 automatically shifts it to B3. This is usually exactly what you want when applying the same calculation down a whole column of different items.

Absolute References

Adding dollar signs — $B$2 — makes a reference absolute: it never changes no matter where the formula is copied. This matters when a formula needs to always point at one fixed cell, like a single discount-rate cell that every row's calculation should share.

Key Point. If copying a formula down breaks it because it "loses" the discount rate, a relative reference is almost always the cause — it should be absolute instead.

Mixed References and F4

A mixed reference locks only the row (B$2) or only the column ($B2) — useful when copying a formula both across and down. Pressing F4 after clicking a reference cycles through relative → absolute → mixed → mixed → back to relative, without retyping dollar signs by hand.
