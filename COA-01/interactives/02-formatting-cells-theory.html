Formatting Cells

Number Formats

The underlying value in a cell and its displayed format are different things. 500 can be displayed as KES 500.00 (Currency format) or 500% (Percentage format) without changing the actual stored number. Home tab → Number group holds these options.

Key Point. Formatting changes only how a number looks, never the underlying value used in calculations.

Borders, Fill, and Sizing

Borders and fill colour (Home tab) make a table easier to scan — a bold border under a header row, or light fill on every other row. Column width and row height can be dragged manually or set to AutoFit (double-click the column border) to exactly match the widest content.

Conditional Formatting

Home → Conditional Formatting applies formatting automatically based on a rule — e.g. "highlight any cell in this column less than 5" to flag low stock red, without checking each row by hand. The formatting updates live as the underlying numbers change.

Key Point. Conditional Formatting is a rule, not a one-time paint job — it keeps re-evaluating as your data changes.
