Formulas and Basic Functions

Formulas Start With =

Typing =5+3 into a cell calculates 8. Typing =B2+B3 calculates using whatever values are currently in B2 and B3 — and updates automatically if those values change. Without the leading =, Excel just stores it as text.

Key Point. Forgetting the = is the single most common reason a "formula" does nothing — Excel just displays it as plain text.

Common Functions

=SUM(B2:B10) adds a whole range. =AVERAGE(B2:B10) finds the mean. =COUNT(B2:B10) counts how many cells in the range contain numbers. =MAX(...) and =MIN(...) find the largest/smallest value. The AutoSum button (Home tab, Σ symbol) inserts =SUM() automatically for a selected range.

Reading Formula Errors

#DIV/0! means a formula tried to divide by zero (or an empty cell). #NAME? usually means a function name is misspelled (e.g. =SUME(...) instead of =SUM(...)). Errors are Excel telling you exactly what kind of mistake to look for.

Key Point. A formula error is not random — the error code itself tells you what category of mistake to check first.
