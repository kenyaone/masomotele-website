PivotTables Basics

What a PivotTable Solves

A raw sales log with one row per transaction (Date, Product, Amount) can have thousands of rows — impossible to read for a "total per product" summary. A PivotTable (Insert → PivotTable) reorganises that raw data into a compact summary table without writing any formulas.

Key Point. A PivotTable summarises; it never modifies or deletes the original raw data it is built from.

The Four Areas

Dragging fields into Rows groups data down the side (e.g. Product). Columns groups data across the top (e.g. Month). Values is what gets calculated for each combination (e.g. Sum of Amount). Filters lets you narrow the whole table to, say, one town only.

Changing the Calculation and Refreshing

By default, a numeric field dropped into Values sums it — this can be changed (right-click the value → Summarize Values By) to Count, Average, Max, etc. If the original raw data changes after the PivotTable is built, the PivotTable does not update by itself — right-click it and choose Refresh.

Key Point. A PivotTable freezes its summary at build time — always Refresh it after adding new raw data rows, or the summary will be out of date.
