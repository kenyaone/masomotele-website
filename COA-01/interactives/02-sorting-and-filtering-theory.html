Sorting and Filtering

Sorting

Selecting a range and using Data → Sort reorders rows based on a chosen column — alphabetically for text, or numerically for numbers, in ascending or descending order. Sorting rearranges entire rows together, so a customer's name and their amount owed stay correctly matched.

Key Point. Always select the whole table (not just one column) before sorting, so related data in each row moves together correctly.

Sorting by Multiple Columns

Data → Sort → Add Level lets you sort by a second column when the first has ties — e.g. sort customers by Town first, then by Amount Owed within each town.

Filtering

Data → Filter adds a dropdown arrow to each column header. Clicking one lets you show only rows matching a condition (e.g. only customers whose "Status" column says "Overdue") while temporarily hiding the rest — the hidden rows are not deleted, just not shown. Clicking the filter dropdown again and choosing "Clear Filter" (or "Select All") brings every row back.

Key Point. Filtering hides rows, it never deletes them — the full data is always still there underneath.
