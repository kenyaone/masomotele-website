Charts and SmartArt in Slides

Charts in Slides

Insert → Chart embeds the same chart types available in Excel (bar, line, pie) directly into a slide, opening a small linked spreadsheet to edit the underlying numbers. This is the same "pick the right chart type for the data" rule from the Excel unit — a trend uses a line chart, categories use bars.

What SmartArt Is For

SmartArt (Insert → SmartArt) turns information into a visual diagram — a process (arrows showing steps in order), a hierarchy (an organisation chart showing who reports to whom), or a relationship (a Venn diagram, a cycle). It replaces a plain bulleted list with something the eye can follow faster.

Key Point. SmartArt suits information that has an inherent structure — steps, hierarchy, or relationships — not a random unordered list of facts.

Converting a List to SmartArt

Selecting an existing bulleted list of steps and choosing Right-click → Convert to SmartArt → a Process layout turns the plain list into a visual flow diagram automatically, keeping the same text.
