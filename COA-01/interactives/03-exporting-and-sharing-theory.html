Exporting and Sharing

PDF Export

File → Export → Create PDF/XPS turns the deck into a fixed, non-editable PDF — good for emailing a static copy of the pitch that will look identical on any device, but it loses animations and video playback.

Key Point. PDF is right for a static leave-behind copy; it is the wrong choice if the deck relies on animations or an embedded video to make its point.

Video Export

File → Export → Create a Video renders the whole presentation — including transitions, animations, and any embedded video/audio — into a single video file the supplier can watch without PowerPoint installed at all, e.g. on a phone.

Printing Handouts

File → Print → under Settings, choosing "Handouts" (e.g. 3 slides per page) prints a paper version with space beside each slide for notes — useful for giving supplier representatives something physical to reference during the meeting.

Key Point. Save keeps working in PowerPoint's own format for further editing; Export produces a different format for people who do not need to edit it.
