Working with Text Boxes and Frames

Text Boxes

Insert → Draw Text Box lets you place a box of text anywhere and give it any size. Unlike Word's continuously flowing page, each text box in Publisher is an independent object that can be moved, resized, or rotated freely.

AutoFit Options

When text does not fit its box, Text Box Tools → Text Fit offers choices: Shrink Text on Overflow (font size reduces automatically to fit), Grow Text Box to Fit (the box expands instead), or Do Not Autofit (text simply overflows visibly, which usually needs manual fixing).

Key Point. Overflowing text that is invisible at the box edge is a common Publisher mistake — check Text Fit settings whenever text seems to disappear.

Linking Text Boxes

When one text box is too small for a long article across a folded brochure, selecting it and using Create Link then clicking an empty box lets the overflow text automatically continue there — exactly how a multi-panel brochure article flows from panel to panel.
