Identifying Basic Computer Parts

The Main Parts

A typical desktop setup has four visible parts: the monitor (the screen that displays everything), the keyboard (for typing text), the mouse (for pointing and clicking), and the system unit or "tower" (the box that holds the actual computer — processor, memory, storage — and does all the real work).

Key Point. The monitor is not "the computer" — it is just the screen. The tower is where the actual computing happens.

Cables

The thick cable from the wall socket is the power cable. Separate thinner cables (often blue, white, or a single HDMI-style cable) connect the monitor, keyboard, and mouse to the tower — these carry data, not power. Mixing these up, or leaving one unplugged, is a common reason "the computer won't turn on".

Turning It On Safely

Most desktops need two power switches turned on: the wall socket switch, and the power button on the tower itself (usually a circular button with a power symbol ⏻). The monitor often has its own separate power button too. All three need to be on for the screen to show anything.

Key Point. If the screen stays black, check all three power switches — wall socket, tower, and monitor — before assuming something is broken.
