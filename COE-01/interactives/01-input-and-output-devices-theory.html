Input and Output Devices

Input Devices

An input device sends information or commands into the computer. Common examples: keyboard (typed text), mouse (clicks and movement), scanner (a paper document becomes a digital image), and microphone (sound becomes digital audio).

Output Devices

An output device presents information that comes out of the computer for a person to perceive. Common examples: monitor (visual display), printer (paper copies), and speakers (sound).

Key Point. A simple test: does it send something TO the computer (input) or give something FROM the computer to a person (output)?

Devices That Do Both

Some devices are both input and output at once — a touchscreen displays output (like a monitor) and accepts input (like a mouse) in the same device. A multi-function printer can print (output) and scan (input) using the same machine.
