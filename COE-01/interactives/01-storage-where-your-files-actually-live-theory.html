Storage: Where Your Files Actually Live

Internal Storage

The hard drive (or faster SSD) inside the tower is where files, programs, and the operating system itself are permanently stored, even after the computer is switched off. This is different from RAM (memory), which is temporary and clears every time the computer restarts — RAM holds what the computer is actively working on right now.

Key Point. RAM is temporary "working space"; storage (hard drive/SSD) is where things stay permanently saved.

Removable Storage

A USB flash drive plugs into a USB port and can be carried between computers — useful for Faith to bring files from home or move records between office computers. An external hard drive works similarly but usually holds much more data.

Cloud Storage

Cloud storage (like Google Drive) saves files on the internet rather than on this specific computer's hard drive — meaning the same file can be opened from a different computer or phone, as long as there is an internet connection. This is different from both internal storage and a USB drive, which are physical and local to one machine.

Key Point. If a file is only saved to this one computer's hard drive, it is not automatically backed up anywhere else — cloud storage or a USB copy are separate safety nets.
