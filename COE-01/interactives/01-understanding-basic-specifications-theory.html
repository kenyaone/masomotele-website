Understanding Basic Specifications

Processor (CPU)

The processor (CPU) is often described as the computer's "brain speed". A higher-end processor handles more demanding tasks (video editing, complex software) more smoothly, but for basic office tasks like typing, browsing, and simple record-keeping, a modest processor is usually sufficient.

RAM

RAM (measured in GB) determines how many things a computer can comfortably work on at the same time. Low RAM (e.g. 4GB) can make a computer feel sluggish when many programs/browser tabs are open at once; more RAM (8GB, 16GB) allows smoother multitasking.

Key Point. RAM affects how many things run smoothly at once; it is not the same as storage space for files.

Storage Capacity

Storage (measured in GB or TB — 1 TB = roughly 1000 GB) is how much data (files, photos, programs) the computer can hold permanently. A receptionist's computer handling mostly documents and records needs far less storage than one handling large video files.

Key Point. Buying the highest specification available is not automatically the right choice — the right specs depend on what the computer will actually be used for.
