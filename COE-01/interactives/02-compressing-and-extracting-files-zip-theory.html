Compressing and Extracting Files (Zip)

What Compression Does

A zip file bundles multiple files/folders into a single, usually smaller, compressed file — much easier to email as one attachment or copy onto a USB drive than dozens of separate files.

Creating a Zip

Selecting several files or a folder, then right-clicking and choosing something like Compress to ZIP file (wording varies slightly by system) bundles them into one new .zip file, leaving the originals untouched.

Key Point. Compressing files does not delete the originals — it creates an additional, bundled copy alongside them.

Extracting

A received .zip file is not directly usable as individual files until it is extracted ("unzipped") — right-click the .zip file and choose Extract All to unpack it back into normal, separate files in a folder.
