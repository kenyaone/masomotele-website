Copying, Moving and Searching

Copy vs Cut vs Paste

Copy (Ctrl+C) duplicates a file — the original stays exactly where it was, and a copy is placed wherever you Paste (Ctrl+V) next. Cut (Ctrl+X) instead removes the file from its original location once pasted elsewhere — there is then only one copy, now in the new location.

Key Point. Use Copy when you want the file in two places; use Cut when you want it moved to just one new place.

Drag and Drop

Clicking and holding a file, then dragging it into a different folder window, moves it there directly — a faster alternative to Cut and Paste for files already visible on screen at the same time.

Searching

Typing part of a file's name into the Search box (in the Start menu or inside a folder window) finds matching files without needing to know exactly which folder they are in — far faster than manually opening folder after folder to look.

Key Point. Searching inside a specific folder window only looks within that folder; searching from the Start menu searches much more broadly across the whole computer.
