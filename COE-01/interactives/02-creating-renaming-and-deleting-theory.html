Creating, Renaming and Deleting

Creating a Folder

Right-clicking an empty area inside a window and choosing New → Folder creates a new, empty folder ready to be named. This is the starting point for any new organisational structure, like a new "August 2026" folder.

Renaming

Right-clicking a file or folder and choosing Rename (or clicking it once, then clicking the name again) lets Faith replace a vague name like "Document1" with something clear and searchable, like "Patient Intake Form - July 2026".

Key Point. A clear, specific file name saved today is what makes that same file findable again in six months.

Deleting and the Recycle Bin

Deleting a file normally moves it to the Recycle Bin (Windows) — a temporary holding area, not permanent removal. Files there can be restored if deleted by mistake, until the Recycle Bin is separately emptied.

Key Point. Deleting a file is usually reversible via the Recycle Bin — but emptying the Recycle Bin itself is not reversible.
