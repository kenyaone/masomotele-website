File Types and Extensions

What Is a File Extension

The short code after the final dot in a file name — like .docx in "Report.docx" — is the file extension, and it tells the computer (and the person) what type of file it is and which program should normally open it.

Common Extensions

.docx = Word document, .xlsx = Excel spreadsheet, .pdf = a fixed-layout document viewable almost anywhere, .jpg/.png = image/photo files. Recognising these at a glance helps Faith know what kind of file she is looking at before even opening it.

Key Point. The extension is a strong hint about which program to use — double-clicking a .xlsx file should normally open Excel, not Word.

A Word of Caution

Some extensions, like .exe, are actual runnable programs rather than documents — opening an unfamiliar .exe file received unexpectedly (e.g. attached to a suspicious email) can install something harmful. Documents (.docx, .pdf, .jpg) are generally safe to open from a trusted source; unfamiliar .exe files deserve caution.

Key Point. An unexpected .exe attachment is a common way malicious software spreads — be cautious rather than double-clicking it automatically.
