Understanding Files and Folders

Files

A file is a single saved item — a document, a photo, a spreadsheet. Each file has a name and usually a small icon showing roughly what kind of file it is (a page icon for a document, a spreadsheet grid icon for Excel files, etc.).

Folders

A folder (sometimes called a directory) is a container used to group related files together — like a physical folder holding related paper documents. Folders can contain other folders too (sub-folders), letting Faith organise records by year, then by month, for example.

Key Point. Think of folders exactly like the physical filing cabinets already used at the front desk — the same organising logic applies on the computer.

Why Organisation Matters

Saving every file loose onto the desktop with no folders makes it slower and slower to find anything as the number of files grows — the same problem as throwing every paper form into one big pile instead of a labelled filing cabinet.

Key Point. A few minutes spent creating sensible folders saves far more time later, every single time a file needs to be found again.
