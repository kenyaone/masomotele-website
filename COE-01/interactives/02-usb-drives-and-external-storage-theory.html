USB Drives and External Storage

Recognising a USB Drive

Plugging a USB flash drive into a USB port usually makes it appear as a new drive in File Explorer within a few seconds, ready to open like any folder.

Copying Files

Files move to or from a USB drive the same way as between any two folders — select the files, Copy (or Cut), then Paste into the USB drive's window (or vice versa, from the USB drive into a folder on the computer).

Safely Removing the Drive

Before physically unplugging a USB drive, using the "Safely Remove Hardware" option (clicking the USB icon in the taskbar, or right-clicking the drive in File Explorer) ensures the computer has fully finished writing any data to it. Pulling the drive out mid-transfer, or without this step, can corrupt the files being written.

Key Point. Never yank a USB drive out while a file transfer is still in progress — wait for it to finish, and safely eject when possible.
