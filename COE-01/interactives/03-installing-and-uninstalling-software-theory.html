Installing and Uninstalling Software

Where Software Comes From

New software should come from a trusted source — the software publisher's official website, or an approved source the IT administrator has confirmed. Downloading random, unfamiliar programs (especially from pop-up ads or unfamiliar websites) risks installing something harmful.

Key Point. If Faith is unsure whether a program is safe or officially approved for the office computer, checking with IT support first is the right move.

The Basic Install Process

Running a downloaded installer file usually opens a setup wizard with a series of "Next" prompts, ending in "Install" or "Finish". Reading each prompt (rather than clicking Next blindly) helps avoid accidentally installing extra unwanted add-ons some installers try to bundle in.

Uninstalling Properly

Simply deleting a program's shortcut icon does not actually remove the software — it just removes the shortcut. Properly uninstalling means going through Settings → Apps (or Control Panel → Programs) and choosing Uninstall for that specific program, which removes it completely.

Key Point. Deleting a shortcut only removes the shortcut, not the underlying installed program — proper uninstalling requires going through Settings/Control Panel.
