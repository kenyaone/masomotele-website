Settings and Personalisation Basics

The Settings App

The Settings app (a gear icon, usually reachable from the Start Menu) is the central place for adjusting how the computer looks and behaves — display, sound, network connections, and more, organised into labelled categories.

Common Everyday Adjustments

Volume can usually be adjusted from a speaker icon in the Taskbar as well as in Settings. Screen brightness and resolution (how sharp/large things appear) are found under Display settings. These are safe, easily reversible adjustments Faith can make confidently.

Wi-Fi and Shared-Computer Caution

Connecting to a Wi-Fi network is done through Settings → Network (or clicking the Wi-Fi icon in the Taskbar directly). On a shared office computer, changes that affect every user (like changing the default printer, or system-wide settings) should be made thoughtfully, ideally after checking with a supervisor or IT — unlike personal, easily-reversible tweaks like volume.

Key Point. Personal-feeling adjustments (volume, brightness) are safe to experiment with; settings that affect every user of a shared computer deserve more caution.
