The Desktop, Start Menu and Taskbar

The Desktop

The Desktop is the main background screen, which can hold shortcut icons to frequently used files or programs. It is one convenient location, not a proper filing system — important files should still live in organised folders, not scattered loosely on the Desktop (see the File Management unit).

The Start Menu

Clicking the Start button (bottom-left corner, usually a Windows logo) opens a menu listing all installed programs, letting Faith launch Word, Excel, or any other software installed on the computer.

The Taskbar

The strip along the bottom of the screen is the Taskbar — it shows currently open programs (so Faith can switch between an open Word document and an open browser), plus the clock and other quick-access icons.

Key Point. Clicking an open program's icon in the Taskbar switches to it instantly, instead of minimising and reopening it from scratch.
