Updates and Basic Security

What Updates Do

Operating system updates regularly fix security weaknesses that could otherwise let harmful software in, alongside general bug fixes and improvements. Postponing updates indefinitely leaves known weaknesses unfixed for longer.

Key Point. An update prompt is not just "annoying nagging" — it is often patching a real security gap that has already been publicly identified.

Antivirus/Security Software

Security software running quietly in the background scans for and blocks known harmful programs. It works best when it is also kept updated (so it recognises newly discovered threats) and not disabled "to make things faster" — a habit that removes real protection.

Recognising Suspicious Activity

A sudden pop-up claiming "Your computer is infected, click here now!", or an email urgently demanding a password reset via an unfamiliar link, are common scam patterns. Pausing to think ("Was I expecting this? Does this look like the real, official version?") before clicking is a simple, effective first defence.

Key Point. Urgency and fear ("act now or lose everything!") is a classic pressure tactic used in scams — genuine notices rarely demand instant, panicked action.
