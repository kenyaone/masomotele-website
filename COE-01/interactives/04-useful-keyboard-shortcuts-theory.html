Useful Keyboard Shortcuts

Copy, Cut, Paste

Ctrl+C copies selected content, Ctrl+X cuts it (removes and copies), and Ctrl+V pastes whatever was last copied or cut. These work the same way across almost every Windows program — Word, Excel, File Explorer, and more.

Undo, Save, Print

Ctrl+Z undoes the last action — a safety net for almost any mistake. Ctrl+S saves the current file immediately without navigating any menu. Ctrl+P opens the Print dialog directly.

Key Point. Ctrl+Z is one of the most broadly useful shortcuts there is — it works for far more than just typing mistakes.

Select All and Find

Ctrl+A instantly selects everything in the current document or folder — much faster than dragging manually over a long document. Ctrl+F opens a Find box to search for a specific word within the current document or webpage, instead of scrolling to look for it manually.
