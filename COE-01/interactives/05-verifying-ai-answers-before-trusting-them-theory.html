Module 5 · Lesson 5.4

Verifying AI Answers Before Trusting Them

Confident but Wrong

An AI assistant can state an incorrect answer in exactly the same confident, clear tone as a correct one — there is no built-in "warning tone" for a wrong answer. This is why Faith should not judge an answer's accuracy purely by how confident or clearly it is written.

Key Point. A confident-sounding answer is not the same thing as a correct answer — these are two completely separate qualities.

A Simple Verification Checklist

Before relying on an AI answer for something important, Faith can ask herself: (1) Is this something I can quickly double-check myself (e.g. by trying the steps)? (2) Does this involve sensitive information (patient data, passwords, money) where being wrong would really matter? (3) If unsure, would a supervisor or IT support give a more reliable answer for this specific situation?

Building Confidence Over Time

Every beginner makes mistakes while learning computers — clicking the wrong thing, forgetting a step, misunderstanding an instruction. This is a completely normal part of building real confidence, whether learning from a colleague, a manual, or an AI assistant — not a sign that something is wrong with Faith personally.
