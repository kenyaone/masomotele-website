What AI Assistants Can Help With Day-to-Day

What an AI Assistant Is

An AI chat assistant (like ChatGPT or similar tools) is a program Faith can type questions to in plain everyday language, and it types back an answer — similar to messaging a very well-read colleague, except it is software, not a person, and it can sometimes be wrong.

Everyday Helpful Uses

Useful day-to-day uses for someone new to computers include: asking it to explain an unfamiliar computer term in simple words, helping draft a polite message to a colleague, or suggesting how to phrase something clearly. It is a helpful starting point, especially for someone still building confidence with writing on a computer.

Key Point. Think of an AI assistant as a fast, always-available first draft helper — not a replacement for double-checking important details yourself.

Asking Clearly

A vague question ("help me with this") gets a vague answer. A specific question ("explain what a USB port is, in simple terms, for someone using a computer for the first time") gets a genuinely useful, tailored answer. The clearer the question, the more useful the response.
