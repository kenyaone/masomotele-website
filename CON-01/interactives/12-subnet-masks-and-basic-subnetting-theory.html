Subnet Masks and Basic Subnetting

1. What a subnet mask does

A subnet mask tells a device which part of an IP address identifies the network, and which part identifies the specific host (device) on that network. For example, with the common mask 255.255.255.0 (written as /24), the first three numbers identify the network, and the last number identifies the specific device.

2. CIDR notation

CIDR (Classless Inter-Domain Routing) notation writes the subnet mask as a slash followed by the number of "network" bits -- /24 means the first 24 bits (the first three octets) are the network portion. A /24 network gives 256 total addresses (0-255 in the last octet), with 254 usable for actual devices (the first and last are reserved for the network address and broadcast address).

3. Splitting a /24 into smaller pieces -- the basic idea

CIDRSubnet maskUsable addresses per subnet
/24255.255.255.0254
/25255.255.255.128126
/26255.255.255.19262

Each step from /24 to /25 to /26 borrows one more bit from the host portion for the network portion, splitting the address space into progressively smaller (but more numerous) subnets. A /25 splits one /24 into 2 subnets; a /26 splits it into 4.

4. What this course deliberately skips

Scope note: full subnetting mastery includes VLSM (variable-length subnet masking), route summarization, and working comfortably with odd, non-standard subnet sizes across large enterprise networks. That is genuinely advanced material, covered in more specialised courses -- this course deliberately stays at the foundational level: recognising common subnet sizes and understanding what a subnet mask fundamentally does.
