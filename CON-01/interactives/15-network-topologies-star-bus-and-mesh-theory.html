Network Topologies -- Star, Bus and Mesh

1. Star topology

In a star topology, every device connects individually to a central point -- a switch. This is by far the most common topology in modern networks: if one cable fails, only that one device is affected, and adding or removing devices is simple. Almost every office and home network today is physically a star, centred on a switch or router.

2. Bus topology

In a bus topology, all devices share a single common cable. It was common in early Ethernet networks but is now essentially historical -- a single break anywhere in the shared cable brings down the entire network, and only one device can transmit at a time without collisions. Worth recognising in documentation or exam contexts, but you will rarely, if ever, encounter one being newly installed today.

3. Mesh topology

In a mesh topology, devices connect to multiple other devices directly, creating redundant paths -- if one connection fails, traffic can route around it through another path. A full mesh connects every device to every other device (very resilient, very expensive in cabling); a partial mesh connects only some devices redundantly. Mesh Wi-Fi systems (multiple access points working together) are a common modern consumer example.
