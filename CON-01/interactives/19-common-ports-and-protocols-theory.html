Common Ports and Protocols

1. What is a port?

A port is a numbered "door" on a device that a specific service listens on, letting one device run many different network services simultaneously without them interfering with each other. An IP address gets traffic to the right device; the port number gets it to the right SERVICE on that device.

2. Common ports worth recognising

PortProtocolUsed for
80HTTPRegular, unencrypted web browsing
443HTTPSEncrypted, secure web browsing -- the padlock icon in a browser
21FTPFile transfer
22SSHSecure remote command-line access to a device
25SMTPSending email
53DNSDomain name resolution, covered in the previous topic
You do not need to memorise every port in existence -- recognising this short, genuinely common list covers the large majority of real-world support scenarios at a foundational level.

3. Why firewalls filter by port

A firewall can block or allow traffic based on which port it is heading to -- for example, allowing port 443 (secure web browsing) while blocking port 21 (older, less secure file transfer) on a business network. This is a basic, common form of network security control, covered in more depth in the next unit.
