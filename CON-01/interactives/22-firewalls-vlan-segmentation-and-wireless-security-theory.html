Firewalls, VLAN Segmentation and Wireless Security

1. Firewalls

A firewall controls which network traffic is allowed in or out, based on rules -- by port (covered in the previous unit), by source/destination address, or by other criteria. A firewall can be a dedicated hardware device, built into a router, or software running on an individual computer. Its job is filtering, not detecting or removing malware already inside a network.

2. VLANs -- the basic idea

A VLAN (Virtual LAN) lets one physical switch behave as if it were several separate, isolated networks -- for example, keeping office computers, guest Wi-Fi, and security cameras logically separated even though they might share the same physical switch hardware. This is genuinely useful basic segmentation: if one segment is compromised, the others are not automatically exposed. Deep VLAN trunking configuration is beyond this course's foundational scope -- what matters here is understanding WHY segmentation is valuable.

4. Guest networks

A separate guest Wi-Fi network -- effectively a simple, practical use of the VLAN segmentation idea -- lets visitors get internet access without ever touching the main business network where sensitive files and devices live. This is one of the cheapest, easiest security improvements James recommends on almost every business site visit.
