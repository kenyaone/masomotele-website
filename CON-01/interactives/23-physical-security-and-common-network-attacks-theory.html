Physical Security and Common Network Attacks

1. Physical access is a real risk

Someone with physical access to a switch, router, or server can potentially bypass many digital security measures entirely -- plugging in a rogue device, resetting equipment to factory defaults, or simply stealing hardware containing sensitive data. Physical security is a genuine, foundational part of network security, not a separate topic.

2. Basic physical security measures

  • Keeping networking equipment (switches, routers, servers) in a locked room or cabinet, not an open office area
  • Disabling unused switch ports so a visitor cannot simply plug in an unauthorised device
  • Basic access logging for server rooms in larger organisations

3. Phishing and social engineering

Phishing is a fraudulent attempt, usually by email or message, to trick someone into revealing credentials or clicking a malicious link -- covered in more depth in a dedicated cybersecurity course, but every network technician should be able to recognise the basic pattern and warn clients about it, since compromised credentials often lead directly to a network-level incident.

4. Rogue access points

A rogue access point is an unauthorised Wi-Fi access point connected to a network -- sometimes planted maliciously to intercept traffic, sometimes just an employee plugging in their own unsecured router for convenience without realising the risk. Either way, it creates an uncontrolled, unmonitored entry point into the network, which is why disabling unused switch ports and periodically scanning for unknown wireless networks are genuinely useful basic precautions.
