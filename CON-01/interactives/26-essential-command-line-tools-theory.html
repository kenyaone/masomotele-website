Essential Command-Line Tools

1. ping

ping sends a small test message to a target address and reports whether it responded, and how long the round trip took. It is the fastest way to answer "can this device reach that other device or address at all?" -- the single most common first diagnostic step in networking.

2. ipconfig / ifconfig

ipconfig (Windows) or ifconfig/ip addr (Linux/Mac) shows a device\'s own current network configuration -- its IP address, subnet mask, default gateway and more. This is exactly the tool used to spot an APIPA (169.254.x.x) address, covered earlier in this course, or to confirm a device\'s settings match what is expected.

3. tracert / traceroute

tracert (Windows) or traceroute (Linux/Mac) shows the actual path (each router "hop") traffic takes to reach a destination, and how long each hop takes. This helps pinpoint WHERE along a path a problem is occurring -- useful when ping confirms something is wrong, but not where.

4. A sensible order to use them

A practical sequence: check ipconfig first (does this device even have a sensible IP configuration?), then ping the default gateway (can it reach the local router at all?), then ping a known external address like 8.8.8.8 (can it reach the internet?), then ping a domain name (does DNS work?), and finally tracert if you need to see exactly where along a longer path things are breaking down.
