Passwords and Authentication Basics

Weak vs Strong Passwords

A weak password is short, a common word, or predictable (birthdays, "password123"). Length matters more than complexity tricks — a long, random passphrase is generally stronger than a short password with substituted symbols.

Password Reuse

Reusing the same password across multiple accounts means one breached, unrelated website can expose the same password attackers then try against SafariPay's systems ("credential stuffing") — a major, common real-world attack pattern.

Key Point. A single reused password is only as strong as the weakest, least-secure site it was also used on.

Multi-Factor Authentication (MFA)

MFA requires a second proof of identity beyond just a password — typically something you know (the password) plus something you have (a phone app generating a code) or something you are (a fingerprint). Even if a password is stolen, MFA can still block the attacker without the second factor.

Key Point. MFA is one of the single most effective defences against stolen or guessed passwords — it should be enabled on any account handling sensitive access.

Password Managers

A password manager generates and stores unique, strong passwords per account, so a person only needs to remember one master password — solving the "reuse because remembering many is hard" problem practically.
