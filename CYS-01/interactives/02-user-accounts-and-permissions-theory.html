User Accounts and Permissions

Admin vs Standard Accounts

An administrator (or root, on Linux) account can install software, change system settings, and access nearly everything. A standard user account is deliberately more limited. Doing everyday work (email, browsing, documents) on an admin account means any malware that runs also runs with full admin rights.

Key Point. Using a standard account for everyday work, and only elevating to admin when genuinely needed, limits what malware can do if it ever executes.

File and Folder Permissions

Permissions control who can read (view), write (modify), or execute (run) a file or folder. A customer support agent's account should not have write access to SafariPay's core transaction database files, for example — matching the least-privilege principle from Unit 1.

Shared Accounts

A single shared login used by multiple SafariPay staff removes individual accountability — if something goes wrong, there is no way to know which specific person was responsible. Each person should have their own account, even on a shared workstation.

Key Point. Shared accounts trade a small convenience for a real loss of accountability — avoid them even when it feels faster in the moment.
