Wi-Fi Security

Wi-Fi Security Standards

WPA2 and the newer WPA3 are current, strong Wi-Fi encryption standards. Older standards like WEP are broken and trivially crackable with widely available tools — any network still using WEP is not meaningfully secured at all.

Key Point. If a Wi-Fi network still uses WEP, it should be treated as essentially unsecured, regardless of having a password.

Guest Networks

A separate guest network, isolated from SafariPay's internal systems, lets visitors get internet access without any path to internal servers or employee devices — an important segmentation measure, not just a courtesy.

Hidden SSID and MAC Filtering — Weak Measures

Hiding a Wi-Fi network's name (SSID) or filtering by device MAC address can feel like extra security, but both are trivially bypassed by anyone with basic tools — hidden networks are still detectable, and MAC addresses can be spoofed. These should never be relied on as the actual security mechanism.

Default Router Credentials

Routers often ship with a default admin username/password, sometimes printed on the device itself or well-documented online. Leaving these unchanged lets anyone on the network (or sometimes remotely) potentially reconfigure the router entirely.
