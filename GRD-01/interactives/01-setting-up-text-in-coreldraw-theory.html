Setting Up Text in CorelDraw

Artistic Text vs. Paragraph Text

CorelDRAW gives Ivy two different text modes. Artistic Text is for short, standalone text — a headline, a logo, a single word — and it can be freely stretched, rotated, or fitted along a curved path. Paragraph Text (also called frame text) is for longer copy that needs to flow inside a defined text box, wrap across multiple lines, and support proper paragraph formatting like columns and alignment.

Picking the wrong one causes headaches later: trying to wrap a long paragraph inside Artistic Text is awkward, and trying to bend a single decorative headline along an arc using Paragraph Text does not work the same way.

Adjusting Kerning and Tracking

Kerning is the spacing between two specific letters — used to fix an awkward gap between a particular pair, such as the space that often looks too wide between an “A” and a “V” in a large headline. Tracking is spacing applied evenly across a whole selection of text — used to tighten a headline so it fits a space, or to loosen a line of text for a lighter, airier feel.

In CorelDRAW, both are adjusted through the Character/Text properties, letting Ivy fine-tune a headline at large display sizes where uneven spacing is most noticeable.

Converting Text to Curves Before Print

Convert to Curves (Ctrl+Q) turns editable text into fixed vector shapes, locking in the exact letterforms so they no longer depend on the font being installed on whatever computer opens the file next. This matters because if a file goes to a print shop that does not have the exact font, the software may silently substitute a different font and the whole layout can shift or break.

The safe workflow is to keep an original, editable working file, and convert only a duplicate export copy to curves right before sending it off to print.

Key Point. Always keep an original editable copy of your file. Convert only the export/print copy to curves (Ctrl+Q) — once text becomes curves, it can no longer be edited or spell-checked as text.
