Vector Shapes, the Bezier Tool and Node Editing

Drawing With Basic Shape Tools

For simple geometric elements — a badge background, a button, a border box — Ivy reaches for the basic shape tools: the Rectangle tool (R), the Ellipse tool (E), and the Polygon tool. Each works the same way: click and drag on the canvas to draw the shape at the size and proportions she wants. Holding Ctrl while dragging constrains the shape — a rectangle becomes a perfect square, and an ellipse becomes a perfect circle — which is much faster and more reliable than trying to eyeball equal proportions by hand.

The Bezier Tool for Custom Paths

Basic shapes cannot draw everything — an organic leaf outline, a custom icon, or a logo mark needs a freeform path, and that is exactly what the Bezier tool is for. A plain click places a straight-line node. Clicking and dragging instead places a node and pulls out curve handles, which shape how the path bends into and out of that point. Chaining nodes together this way builds up a custom outline one segment at a time, and pressing Enter (or double-clicking) finishes the path.

Editing Nodes With the Shape Tool

Once a path exists, the Shape tool (F10) is how Ivy refines it. Clicking a node selects it so it can be dragged to a new position; a node can be added along an existing segment, or an unwanted one deleted; and any node can be converted between a sharp "cusp" corner and a smooth "curve" point, changing how the outline flows through it. Dragging a node's curve handles adjusts exactly how tightly or gently the path bends near that point.

Key Point. A rough first pass with the Bezier tool is completely normal — node editing with the Shape tool is what turns that rough sketch into a clean, print-ready outline. This is the skill that separates a beginner CorelDraw user from a confident one.
