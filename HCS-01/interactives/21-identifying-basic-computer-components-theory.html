Identifying Basic Computer Components

1. Core hardware components

ComponentWhat it does
MonitorDisplays what the computer is showing (an output device)
System unit / towerContains the main processing hardware -- the "brain" of the computer
KeyboardUsed to type text and commands (an input device)
MouseUsed to point, select and click on screen (an input device)
Power cableSupplies electricity to the system unit and monitor

2. Input versus output devices

An input device sends information into the computer (a keyboard, a mouse, a scanner). An output device shows or produces information from the computer (a monitor, a printer, speakers). Some devices, like a touchscreen, do both.

3. Common ports and connectors

  • USB port: connects many devices -- keyboard, mouse, USB drive, printer
  • Power port: where the power cable connects to the system unit and monitor
  • Monitor cable port: connects the monitor to the system unit so it can display the picture
  • Network/Ethernet port: connects the computer to a wired hospital network

4. A typical hospital admin desk setup

Mercy says: "At the nurses' station, I have a monitor, keyboard, mouse and a small system unit under the desk, all plugged into the same power strip and connected by a few visible cables. Knowing what each part is called and does means when something isn't working, I can describe it accurately when I report it -- 'the monitor has no picture' is more useful than 'the computer isn't working.'"
