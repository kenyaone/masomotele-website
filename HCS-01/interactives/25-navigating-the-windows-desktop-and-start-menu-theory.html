Navigating the Windows Desktop and Start Menu

1. The Windows desktop at a glance

The desktop is the main screen you see after logging in. Shortcut icons for programs and files sit on the desktop itself, while a long bar runs along the bottom of the screen -- the Taskbar. The Taskbar holds the Start button on the left, icons for currently open programs in the middle, and the System Tray on the right, showing the clock, volume, Wi-Fi status and other background icons.

2. Using the Start Menu

Clicking the Start button opens the Start Menu -- a list of installed programs plus a search box. Rather than hunting through folders of icons, the fastest way to open almost anything is to click Start and simply type the first few letters of the program's name; Windows filters the list instantly as you type.

3. The Taskbar and switching between windows

Every program you have open gets its own icon on the Taskbar. Clicking that icon brings the program back to the front without closing it. The keyboard shortcut Alt+Tab does the same thing -- hold Alt and press Tab to cycle between open windows, which is often faster than reaching for the mouse.

Mercy says: "On my first day on the ward's shared computer, I didn't know where anything was. Now I just click Start and type the first few letters of whatever I need -- Word, the scheduling program, anything. I don't waste time hunting through icons."
