Basic Settings, Control Panel and Managing Windows

1. Opening Settings

The Settings app (the gear icon, also reachable by searching "Settings" from the Start Menu) is where most everyday adjustments live: Display, Sound, Network & Internet, Devices, and Date & Time are the categories used most often in a shared office computer.

2. Common everyday adjustments

TaskWhere to find it
Adjust volumeSpeaker icon in the System Tray, or Settings > Sound
Adjust screen brightnessSettings > System > Display
Check or fix date/timeSettings > Time & Language
Connect to Wi-FiSettings > Network & Internet

3. Connecting to a shared printer or network drive

Never guess which printer you're sending to. In a hospital setting, sending a report to the wrong department's printer is a real confidentiality slip, not just an inconvenience -- the document could sit, unattended, on a printer tray somewhere it shouldn't be seen. Printers and shared drives are added and managed from Settings > Devices > Printers & Scanners.

4. File Explorer basics

File Explorer is the tool for browsing, renaming and organising saved files and folders. Saving documents into a clearly named folder -- rather than scattering them across the desktop -- makes them far easier to find again later, and the Search box inside File Explorer can locate a file by name even if you've forgotten exactly where you saved it.
