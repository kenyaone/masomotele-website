Lesson

Working with Tables, Lists and Printing

1. Inserting a table

Tables organise information into clear rows and columns -- useful for something like a daily supply count. From the Insert tab, choosing Table and selecting the number of columns and rows creates a ready-to-fill grid, such as a simple 3-column table for Item, Quantity and Notes.

2. Adding rows and columns

If more space is needed than originally planned, clicking in the last cell of a table and pressing Tab automatically adds a new row, or a row/column can be inserted at a specific point via a right-click menu.

3. Bulleted vs numbered lists

Mercy says: "For handover instructions, I use a numbered list because the order actually matters -- step 1 before step 2. For a general list of supplies with no particular order, a plain bulleted list is enough."

4. Print Preview and printing

Before sending a document to a printer, File > Print shows a preview of exactly how the pages will look, alongside a list of available printers to choose from. Checking both the layout and the selected printer before clicking Print avoids wasted paper and, in a shared office, avoids a document landing on the wrong printer.
