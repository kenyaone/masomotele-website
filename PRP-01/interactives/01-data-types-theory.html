Data Types

1The Four Basic Data Types

Python has several built-in data types. The four you'll use constantly are:

  • str (string) — text, always in quotes, e.g. "Eldoret"
  • int (integer) — a whole number, e.g. 25
  • float — a decimal number, e.g. 49.99
  • bool (Boolean) — either True or False
name = "Kipchoge"   # str
age = 25             # int
price = 49.99         # float
is_student = True     # bool

2Checking a Value's Type

The built-in type() function tells you what type a value or variable is — useful when you're not sure, or when debugging.

age = 25
print(type(age))
# Output: <class 'int'>

3Why Type Matters

Python only lets you do certain operations on certain types — you can add two numbers, but adding a number to text directly causes an error. Knowing a value's type helps you predict how your code will behave.
