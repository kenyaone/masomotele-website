Getting User Input

1The input() Function

The input() function makes a program interactive — it displays a message (the prompt), pauses and waits for the user to type something, then stores whatever they typed in a variable.

name = input("What is your name? ")
print("Hello, " + name + "!")

2input() Always Returns a String

No matter what the user types — even if it looks like a number — input() always gives you back a string (str). This matters a lot once you want to do maths with what the user typed — you'll see how to fix that in the next lesson.

age = input("How old are you? ")
print(type(age))
# Output: <class 'str'> — even if the user typed 20
