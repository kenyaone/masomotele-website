Type Conversion and Formatting Output

1Why Conversion Matters

Since input() always returns a string, trying to do maths with it directly causes an error. To fix this, Python provides conversion functions: int("25") turns the string "25" into the whole number 25, and float("3.14") turns "3.14" into the decimal number 3.14.

age_text = input("How old are you? ")   # a string, e.g. "20"
age_number = int(age_text)                 # now a real int
print("In 5 years you'll be", age_number + 5)

2Converting the Other Way

str() does the opposite — it converts a number into a string, useful when you want to join it directly with other text using +.

score = 95
message = "Your score is " + str(score)
print(message)

3Putting It All Together

Combining input() with a conversion function in one line is a very common pattern — it reads the input and converts it immediately.

age = int(input("How old are you? "))
print("Next year you'll be", age + 1)
