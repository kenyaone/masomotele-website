List Methods

1Adding Items with append()

append() adds a single item to the end of a list — it changes the list directly, rather than returning a new one.

courses = ["CompApps", "Nursing"]
courses.append("WebDev")
print(courses)   # ['CompApps', 'Nursing', 'WebDev']

2Removing Items with remove()

remove() removes the first item that matches the given value.

courses.remove("Nursing")
print(courses)   # ['CompApps', 'WebDev']

3Sorting with sort()

sort() arranges a list's items in order (ascending by default), changing the list itself.

numbers = [5, 2, 8, 1]
numbers.sort()
print(numbers)   # [1, 2, 5, 8]
