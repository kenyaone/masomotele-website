1. The 8 essential parts

  1. Homepage — front door + navigation hub
  2. Company info — About page
  3. Contact — phone, email, address, form
  4. News / blog — regular updates
  5. Services / product descriptions — what you sell
  6. Search — a search box
  7. E-commerce — checkout, if you're selling
  8. Sitemap — map for search engines + lost visitors
Sarah needs the first 5. Not all 8 — no checkout (WhatsApp handles that), no separate blog yet.

2. UI vs UX

🎨 UI — User Interface

What it looks like. Buttons, menus, forms, colours.

💚 UX — User Experience

How it feels. Overall satisfaction using the site.

A beautiful UI with bad UX is a site that looks like a magazine but frustrates the customer. Good UX often means less UI: fewer buttons, fewer choices, clearer language.

3. The 6 design terms

Responsive design

Rearranges for phone/tablet/laptop. Non-negotiable in Kenya (87% mobile).

Accessibility

Works for screen readers + keyboard-only users.

Performance

Under 3 seconds to load, or lose half your visitors.

Browser compatibility

Works in Chrome, Safari, Edge, Firefox — not just what you tested.

UI

Buttons, forms, colours — what you see.

UX

The felt experience of using the site.

4. The 6 content practices

  1. Audience-focused — write for your customer, not for yourself
  2. Clear + concise — no jargon, no long sentences
  3. Keywords natural — don't stuff
  4. Consistent brand voice
  5. High-quality images — professional, sharp, relevant
  6. Regularly updated — an "About Us" from 2020 is a red flag
