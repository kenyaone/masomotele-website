6. The publishing checklist

Before you click Publish on ANY page, run through this five-item checklist:

  1. Title matches URL — clear and readable.
  2. Featured image is set — appears in social share previews.
  3. Heading levels correct — H1 for page title, H2 for main sections, H3 for sub-sections.
  4. Every button has a real URL — no placeholder # links.
  5. Mobile preview looks right — click the phone icon at the top of the editor.
Only then click Publish. A single missed step (wrong featured image, broken button URL) can mean months of ugly social previews or broken checkout flows.

7. Self-check quiz

1. Which is NOT one of the 5 essential pages?

Correct — sitemap is a file, not a page. The five are Home, About, Menu, Delivery, Contact.

2. Which block builds a full-width hero image with text?

Correct — Cover is designed exactly for hero sections.

3. How many H1 headings per page?

Correct — one H1 per page. Use H2/H3 for sections.

4. What does the "featured image" do?

Correct — the meta thumbnail for shares.

5. Which block is best for a menu with 4 categories side-by-side?

Correct — Columns handles 2/3/4 column layouts.

6. Sarah's Contact page MUST include…

Correct — every way a customer can reach you AND a form for those who prefer typing.

7. Which is a common publishing mistake?

Correct — placeholder URLs create broken buttons in production. Always test.

8. What should Sarah's Home hero CTA link to?

Correct — the primary CTA on Home should drive to the ordering channel.

9. Before Publish, check the mobile preview because…

Correct — mobile-first isn't optional in Kenya.

10. Sarah has 5 pages published but no top navigation. What's the fix?

Correct — navigation is set explicitly in Appearance → Menus.
