4. Prerequisites — check before you download

Studio is lean by modern standards, but if your machine is under-spec Studio will crash mid-install. Confirm all four before Step 1.

💻 OS version

Windows 10+, macOS 12+, or Ubuntu 22.04+. Older versions unsupported.

💾 Free disk space

4 GB minimum. Each Studio site takes ~200 MB.

🌐 Internet

Needed for the initial download. After install Studio runs 100% offline.

🔒 Admin rights

Installer needs to add to Program Files or /Applications.

Antivirus warning: Some Kenyan corporate laptops have Sophos or Kaspersky that flag the Studio installer as unknown. Ask IT to whitelist Automattic before you download.

5. Common install problems — and their fixes

Problem 1: Antivirus blocks the installer

Fix: Temporarily disable your antivirus during install, then turn it back on. Studio is genuinely safe.

Problem 2: Studio installs but a site won't start

Fix: Ports 80 and 443 are in use by another program. Open Task Manager and end any Apache, MAMP, or XAMPP processes.

Problem 3: The local URL won't open in the browser

Fix: Your hosts file may be blocking it. Restart the computer once. If it still fails, run Studio as Administrator on Windows.

Problem 4: "Signature verification failed" on macOS

Fix: System Settings → Privacy & Security → scroll to the blocked-app notice → click "Open Anyway". macOS Gatekeeper needs one-time approval.

7. What you should see after a successful install

Sanity-check screen. If your first launch of Studio matches this, you're done. If anything is missing, restart from Step 1.

  1. Sidebar shows 4 items — My Sites, Import Site, Settings, Help.
  2. Main pane shows an empty state — a big "+ Add site" card in the centre.
  3. Title bar reads "WordPress Studio" — not "Local by Flywheel" or anything else.
  4. Settings → About shows version 1.4 or higher — older builds are missing the Demo Sites feature.
  5. No sign-in required — Studio works fully without a WordPress.com account (sign-in is optional, only needed for Demo Sites sharing).
Next tap: click the big "+ Add site" card. Name it Karibu Kitchen. Accept the default PHP 8.3. Studio spins up a full WordPress in about 10 seconds. Log in with the auto-generated credentials Studio shows on the site card — and you are ready for Lesson 8.4.
