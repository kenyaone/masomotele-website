4. Events API toggle + dedup diagram

The Pixel runs in the browser and is blocked by iOS 14.5 App Tracking Transparency. The Events API runs server-side and cannot be blocked. Run both together, dedup by event ID.

Recovery: Pixel + Events API together recover roughly 30–40% of the conversions Brian would otherwise miss on iOS. Same event fires twice; a shared event_id lets TikTok dedup so nothing double-counts.

5. Automatic Advanced Matching

When switched on, the Pixel hashes email addresses and phone numbers it finds on the page (e.g. in the Shopify checkout form) and sends them with each event. Higher match rate. Legal because the data is hashed before it leaves the browser.

Automatic Advanced Matching Auto-hash email + phone from checkout forms
ON — Match rate 84%. Chapa Fitness sees 61 attributed purchases on 7-day click. Iphone traffic recovered.
Hashed but still PII: Kenya DPA 2019 treats hashed email/phone as personal data. You still need explicit consent before enabling this. Handled by CookieYes on chapafitness.co.ke.

7. Kenya DPA 2019 — non-negotiable

Brian cannot track visitors silently. The Kenya Data Protection Act 2019 treats IP + browser fingerprint (and any hashed PII) as personal data. Three obligations.

  1. Cookie banner on first visit with a genuine Reject option — not just Accept.
  2. Privacy policy naming TikTok as a data processor and explaining what is sent, including hashed email/phone via the Events API.
  3. Withdraw consent at any time — a persistent link or preference centre.
When a visitor rejects tracking: both the Pixel AND the Events API must be blocked. Chapa Fitness uses CookieYes on Shopify — a Reject click sets a consent flag; the Shopify server checks the flag before firing any server event; the browser tag manager skips the Pixel base code. Rejected visitors are not tracked. Same rule as Sarah's site in Lesson 11.2.

8. Self-check quiz

1. Why do you need the Events API on top of the Pixel?

Correct — the Events API is server-side and cannot be blocked by iOS or ad blockers.

2. How does TikTok avoid double-counting the same event from Pixel AND API?

Correct — same event_id from two sources = counted once.

3. Brian's Shopify store — which install path is correct?

Correct — the official Shopify app is the fastest and safest path for Chapa Fitness.

4. Which event fires on the thank-you page?

Correct — Purchase carries the transaction value and currency.

5. Automatic Advanced Matching sends what to TikTok?

Correct — SHA-256 hashed PII. Raises match rate, still counts as personal data under Kenya DPA.

6. Which browser tool verifies each Pixel event?

Correct — the Pixel Helper shows every fired event with its ID and params.

7. Kenya DPA 2019 requires which of these on chapafitness.co.ke?

Correct — three obligations. Consent, transparency, withdrawal. Enforced by the ODPC.

8. When a visitor rejects tracking, what must happen?

Correct — a reject click must stop both client and server tracking. Otherwise the server bypasses the consent.
