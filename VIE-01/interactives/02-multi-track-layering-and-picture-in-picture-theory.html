Multi-Track Layering and Picture-in-Picture

Track Order Controls What's On Top

In CapCut, the main video sits on the bottom track, and every clip added as an overlay stacks above it on its own track. During playback, whichever track sits highest in that stack renders on top of everything beneath it. Otieno relies on this constantly: his studio logo watermark needs to stay visible above both the main footage and any other overlay, so it has to sit on the topmost track of all.

Clips placed on the same track can't overlap each other — they simply play one after another. Layering only happens between clips on different, stacked tracks.

Opacity and Blending an Overlay

An overlay clip's Opacity setting (found in CapCut's overlay edit panel) controls how see-through it is, from 0% (invisible) to 100% (fully solid). A logo watermark is usually set to a partial opacity — visible enough to clearly identify Eldoret Reels Studio as the source, but low enough that it doesn't distract from the footage underneath.

Positioning and Sizing a Picture-in-Picture Clip

A picture-in-picture (PIP) clip — for example, a guest's reaction shot layered over the main ceremony footage — is dragged and resized directly on the preview canvas using its on-screen handles. Otieno typically keeps a PIP clip in a corner (commonly bottom-right) and sized at a modest fraction of the full frame, so it stays clearly visible without covering the main action happening in the centre of the shot.

Key Point. Place the logo on the topmost track so it always stays visible; keep its opacity moderate so it reads clearly without overpowering the shot; and size/position a PIP clip in a corner, large enough to see but small enough to leave the main action fully visible.
