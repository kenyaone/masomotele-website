Exporting & Rendering · Lesson 3

Exporting for Instagram Reels, TikTok, YouTube, and WhatsApp Status

Aspect Ratio and Auto Reframe

Aspect ratio is the shape of the video frame. Instagram Reels, TikTok, and WhatsApp Status all expect vertical, 9:16 video, filling a phone screen top to bottom. A standard YouTube upload expects horizontal, 16:9 video, the traditional widescreen shape. Some destinations also use 1:1 square framing for feed posts.

If Otieno edits a clip in one aspect ratio but needs to deliver it in another, simply stretching or squashing the frame distorts the picture. CapCut's Auto Reframe and Canva Video's Resize tool instead intelligently recrop the footage to the new aspect ratio, keeping the main subject centred and properly proportioned rather than warped.

Duration Expectations Per Platform

Each destination has its own realistic length expectations. Instagram Reels and TikTok favour short-form vertical clips, typically well under a minute for the best engagement. A standard YouTube upload has no strict duration cap and can comfortably hold a full-length highlight reel. WhatsApp Status specifically limits each individual status post to about 30 seconds, so a longer clip must be trimmed (or split into multiple Status posts) to fit.

File Size and Compression for Quick Sharing

WhatsApp Status, in particular, benefits from a small, quickly-loading file, since it is viewed directly inside a chat app over whatever data connection the viewer has. Reels and TikTok apps handle their own compression on upload, so Otieno's export doesn't need to be tiny for those, but starting from a reasonably sized, non-bloated export still uploads faster and avoids extra processing time.

Because these constraints differ so much by destination, Otieno keeps one master edit and exports separate versions for each platform, rather than trying to make one single export file serve every destination equally well.

Key Point. Match aspect ratio, duration, and file size to the real constraints of each destination: 9:16 vertical and under a minute for Reels/TikTok, 16:9 horizontal with no strict duration cap for a standard YouTube upload, and 9:16 vertical, roughly 30 seconds, small file size for WhatsApp Status.
