How the Web Works

Client and Server

A web page involves two computers talking to each other: your browser (the client) and a web server somewhere else, storing the site's files. Typing a web address and pressing Enter sends a request to that server, asking for a specific page.

Request and Response

The server receives the request, finds (or generates) the matching HTML file, and sends it back as a response. The browser then reads that HTML and draws it on screen as the page you actually see — this whole round trip usually happens in well under a second.

Key Point. The HTML file itself never "looks like" a webpage until a browser interprets and renders it — the file is just structured text.

Domain Names and IP Addresses

Servers are actually located using numeric IP addresses — a domain name like nakuruhardwarehub.co.ke is a human-friendly label that a DNS lookup translates into the real IP address behind the scenes, before the request is actually sent.
