HTML Forms

The form Element

A <form> wraps a group of input fields meant to be submitted together, with action (where the data goes) and method (how it is sent) attributes controlling what happens on submission.

Common Input Types

<input type="text"> for short text, type="email" for an email address (with built-in basic validation), type="tel" for a phone number, and <textarea> for longer multi-line text.

Labels Matter

A <label> associated with each input (via a matching for/id pair) makes the field's purpose clear to sighted users and screen readers alike, and lets clicking the label text focus the input — a real usability improvement, not just decoration.

Key Point. An unlabeled input field is a common, easily-avoided accessibility and usability gap.
