HTML Validation and Accessibility

Validating HTML

An HTML validator checks a page against the official HTML standard, flagging errors like unclosed tags or invalid nesting — code that "looks fine" in one browser can still be invalid and behave unpredictably elsewhere.

Basic Accessibility Habits

Beyond alt text and labeled forms (covered earlier), sufficient colour contrast between text and background, a logical heading order (not skipping from h1 straight to h4), and keyboard-navigable interactive elements are all foundational accessibility practices.

Key Point. Accessibility is not a separate add-on step at the end — it is built in through the same semantic, well-structured HTML habits covered throughout this unit.

Why This Matters for Nakuru Hardware Hub

A real customer using a screen reader, or simply an older device with a small screen, needs the site to actually work for them — accessible, valid HTML is not an abstract standard, it directly determines whether a real visitor can use the site at all.
