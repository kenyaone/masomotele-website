Images and Media

The img Element

<img> embeds an image and, unlike most HTML elements, has no closing tag — it is "self-closing". Its src attribute points to the image file, and its alt attribute provides a text description.

Why alt Text Matters

The alt attribute is read aloud by screen readers for visually impaired visitors, and is what displays if the image fails to load — skipping it is a real accessibility gap, not just a missed detail.

Key Point. An image with no alt text is effectively invisible to a screen reader user — this is one of the simplest, highest-impact accessibility fixes available.

Image File Formats

JPG suits photographs, PNG suits graphics needing transparency (like a logo), and modern formats like WebP often give smaller file sizes at similar quality — smaller images generally mean a faster-loading page.
