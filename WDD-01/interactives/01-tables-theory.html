Tables

Table Structure

A table starts with <table>, containing rows (<tr>), which contain cells — either <td> for a normal data cell or <th> for a header cell.

Header Cells Matter

Using <th> for header row cells (instead of just bolding a <td>) tells both browsers and screen readers that a cell is a header — this has real accessibility and semantic meaning, not just a visual difference.

Key Point. A visually bold &lt;td&gt; and a semantic &lt;th&gt; can look identical but mean very different things to assistive technology.

When (Not) to Use a Table

Tables are for genuinely tabular data — rows and columns of related values, like a price list. Using a table purely to control page layout (positioning unrelated content side by side) is an outdated, discouraged practice — CSS layout tools like Flexbox and Grid exist for that.
