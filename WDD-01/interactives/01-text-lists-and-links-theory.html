Text, Lists and Links

Headings and Paragraphs

<h1> through <h6> are headings, in decreasing importance — a page should generally have exactly one <h1>. Regular text goes in <p> (paragraph) elements, not just typed loosely into the body.

Lists

An unordered (bulleted) list uses <ul> with each item wrapped in <li>. An ordered (numbered) list uses <ol> the same way — the browser adds the bullets or numbers automatically based on which wrapper element is used.

Links

The <a> (anchor) element creates a clickable link, with the destination set in its href attribute: <a href="products.html">Our Products</a>. The text between the tags is what the visitor actually sees and clicks.

Key Point. Link text like "click here" tells a visitor nothing about where the link goes — descriptive link text ("View Our Products") is both clearer and better for accessibility.
