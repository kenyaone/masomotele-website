Your First HTML Page

The Basic Skeleton

Every HTML page starts with the same skeleton: <!DOCTYPE html> tells the browser this is a modern HTML document, then a single <html> element wraps everything else, containing exactly one <head> and one <body>.

Head vs Body

The <head> holds information about the page that is not directly displayed — the page title shown in the browser tab, links to stylesheets, character encoding. The <body> holds everything that actually appears on the page — headings, paragraphs, images, links.

Key Point. Content placed in the head, like the title, never appears directly inside the page itself — only in the browser tab or search results.

Tags Usually Come in Pairs

Most HTML elements have an opening tag and a matching closing tag, like <h1>Hello</h1> — the closing tag has a forward slash. Forgetting a closing tag is one of the most common early mistakes and can make the rest of the page render unpredictably.
