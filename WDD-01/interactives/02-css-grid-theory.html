CSS Grid

Two-Dimensional Layout

display: grid lets an element lay out its children in both rows and columns simultaneously — grid-template-columns: repeat(3, 1fr) creates three equal-width columns, for example.

Placing Items

Grid items can be explicitly placed into specific rows/columns, or simply flow into the next available cell automatically — giving precise control when needed, without requiring it for every single item.

Grid vs Flexbox

Grid suits a genuinely two-dimensional layout (a photo gallery, a full page layout with header/sidebar/main/footer); Flexbox suits a single row or column of items. Many real pages use both together — Grid for overall page structure, Flexbox within individual sections.

Key Point. Choosing Grid vs Flexbox is about dimensionality — one axis of alignment (Flexbox) vs two (Grid) — not that one tool is simply "better" than the other.
