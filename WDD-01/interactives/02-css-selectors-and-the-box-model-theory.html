CSS Selectors and the Box Model

Selectors: Targeting What to Style

A selector decides which HTML elements a CSS rule applies to — p targets every paragraph, .price targets every element with class="price", and #logo targets the single element with id="logo".

Class vs ID

A class can be reused on many elements (multiple items sharing class="card"); an ID should appear only once per page. Classes are the right default for reusable styling; IDs suit a single unique element like a page's main header.

Key Point. Reaching for an ID when a class would do makes that styling harder to reuse elsewhere on the page later.

The Box Model

Every element is a rectangular box made of four layered parts, from the inside out: content, padding (space inside the border), border, and margin (space outside the border, between elements). Understanding this layering explains most "why is there unexpected space here" layout questions.
