CSS Variables and Architecture

CSS Custom Properties

A CSS variable (formally a "custom property"), like --brand-green: #387633;, is defined once and reused throughout a stylesheet via var(--brand-green) — changing the single definition updates every place it is used.

Why This Matters at Scale

Without variables, changing a brand colour used in fifty places means finding and editing fifty separate hex codes; with a variable, it means editing one line — the same "change it once, update everywhere" benefit Styles provided in Word.

Key Point. CSS variables solve the exact same "single source of truth" problem that Word Styles and PowerPoint Themes solve in their own domains.

Organising a Growing Stylesheet

As a site grows, organising CSS into logical sections (variables, base/reset styles, layout, components) — rather than one long unorganised file — keeps the stylesheet maintainable as more people and more pages get added over time.
