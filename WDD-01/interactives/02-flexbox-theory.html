Flexbox

What Flexbox Solves

display: flex turns an element into a flex container, arranging its direct children along a single row or column automatically — solving layout problems (evenly spacing items, centering content) that used to need awkward workarounds.

Main Axis and Alignment

justify-content controls spacing along the main axis (e.g. spreading items evenly across a row), while align-items controls alignment across the other axis (e.g. vertically centering items in a row).

Key Point. Flexbox's "main axis" changes direction depending on flex-direction — row (default) runs left-to-right, column runs top-to-bottom, and justify-content always follows that main axis.

When Flexbox Fits

Flexbox excels at one-dimensional layout — a single row of navigation links, a row of product cards. For genuinely two-dimensional layout (rows and columns together), CSS Grid (next lesson) is usually the better fit.
