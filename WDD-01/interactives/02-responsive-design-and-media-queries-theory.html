Responsive Design and Media Queries

Why Responsive Design Matters

A site viewed on a large desktop monitor and on a small phone screen needs to adapt — a fixed layout designed only for one screen size will look broken or unusable on the other.

Media Queries

A media query like @media (max-width: 600px) { ... } applies CSS rules only when the browser window matches that condition — letting a 3-column layout collapse to 1 column on a small screen, for example.

Key Point. Media query breakpoints should be chosen based on where a design actually starts to look cramped or awkward, not just at arbitrary "standard" device widths.

Mobile-First vs Desktop-First

A mobile-first approach writes the base CSS for small screens, then uses media queries to add complexity for larger screens — often produces simpler, more maintainable CSS than starting from a complex desktop layout and trying to simplify it down.
