Typography

Font Family and Fallbacks

font-family lists preferred fonts in order, ending in a generic fallback like sans-serif — if the first font is not installed on a visitor's device, the browser tries the next, down to the generic fallback.

Readable Sizing and Spacing

font-size, line-height (space between lines), and letter-spacing together determine how comfortable text actually is to read — cramped line-height is a common, easily-fixed readability mistake.

Key Point. A line-height around 1.5 for body text is a widely-used, comfortable default — much tighter than that starts to hurt readability.

Font Weight and Style

font-weight (normal, bold, or a numeric value like 600) and font-style: italic add emphasis — but like in Word, stacking too many emphasis styles on one piece of text reduces clarity rather than adding it.
