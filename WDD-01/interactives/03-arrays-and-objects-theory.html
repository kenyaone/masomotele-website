Arrays and Objects

Arrays

An array holds an ordered list of values: const products = ["Cement", "Timber", "Nails"]; — individual items are accessed by their position (index), starting at 0, so products[0] is "Cement".

Objects

An object holds related data as named key/value pairs: const product = { name: "Cement", price: 850 }; — accessed by name (product.price) rather than position, better suited to grouping different properties of one thing.

Arrays of Objects

Real data is often an array of objects — a list of products, each one an object with its own name/price/stock — combining both structures to represent something like a full product catalogue.

Key Point. This array-of-objects pattern is extremely common in real code — it is worth becoming comfortable reading and writing it early.
