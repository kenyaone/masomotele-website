Conditionals and Loops

if/else Conditionals

if (stock > 0) { ... } else { ... } runs different code depending on whether a condition is true or false — the fundamental building block of any decision-making in code.

Comparison and Logical Operators

=== checks strict equality (matching both value and type), >/< compare numbers, and &&/|| (and/or) combine multiple conditions into one — if (stock > 0 && inStore) requires both conditions true.

Key Point. Using === (strict equality) rather than == (loose equality) avoids a common category of confusing JavaScript bugs caused by automatic type conversion.

Loops

A for loop repeats a block of code a set number of times — essential for going through every item in a list of products, for example, without writing near-identical code once per item.
