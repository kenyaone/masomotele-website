Events

What an Event Is

An event is something happening in the browser — a click, a key press, a form submission, a page finishing loading. JavaScript can "listen" for these events and run code in response.

Event Listeners

button.addEventListener("click", function() { ... }) attaches a response to a specific event on a specific element — the code inside only runs when that button is actually clicked, not immediately when the page loads.

The Event Object

The function responding to an event usually receives an event object with useful details — which key was pressed, which element was actually clicked (useful when several similar elements share one listener).

Key Point. Event-driven code is fundamentally different from top-to-bottom script execution — it waits, potentially indefinitely, for something to actually happen.
