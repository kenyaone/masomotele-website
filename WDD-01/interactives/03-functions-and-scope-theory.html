Functions and Scope

Defining and Calling Functions

A function is a named, reusable block of code: function greet(name) { return "Hello, " + name; } defines it; greet("Sarah") actually runs it with a specific input.

Parameters and Return Values

Parameters (like name above) let a function work with different inputs each time it is called; return sends a value back out to wherever the function was called from, which can then be stored or used further.

Scope

A variable declared inside a function is only accessible inside that function (its own local scope) — it does not leak out and clash with a similarly-named variable elsewhere in the code, which keeps functions self-contained and easier to reason about.

Key Point. Scope is what lets two different functions each safely use a variable named "total" without interfering with each other.
