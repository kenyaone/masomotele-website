Local Storage

What Local Storage Is

localStorage lets JavaScript save small pieces of text data directly in the visitor's browser, which persists even after the page is closed and reopened — useful for remembering a preference like a chosen theme.

Reading and Writing

localStorage.setItem("theme", "dark") saves a value; localStorage.getItem("theme") reads it back later, even in a completely new visit to the page.

What It Is Not For

Local storage is not encrypted and is easily viewed or edited by anyone with access to that browser — genuinely sensitive information (passwords, private data) should never be stored there.

Key Point. Local storage suits harmless convenience data (a UI preference, a cart's contents) — never data that would matter if someone else on the same device could read or change it.
