The DOM

What the DOM Is

The DOM (Document Object Model) is the browser's live, in-memory representation of the page's HTML as a tree of objects — JavaScript can read and change this tree, and the visible page updates immediately to match.

Selecting Elements

document.querySelector(".price") finds the first matching element; document.querySelectorAll(".price") finds all of them — using the same CSS-style selectors already familiar from styling.

Changing Content

Once an element is selected, its content or appearance can be changed directly in JavaScript — element.textContent = "Sold Out" updates the visible text instantly, without needing to reload the page.

Key Point. This is exactly what makes a page feel "interactive" rather than static — JavaScript modifying the DOM in response to something happening.
