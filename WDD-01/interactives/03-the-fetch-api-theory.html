The Fetch API

What Fetch Does

fetch(url) sends an HTTP request from JavaScript to a server — commonly used to load fresh data (like current stock levels) without reloading the whole page.

Fetch Is Asynchronous

A fetch request takes some real time to complete (the server has to respond), so fetch does not pause the rest of the code waiting — instead it returns a Promise, and .then() or await is used to handle the response once it actually arrives.

Key Point. Code that assumes a fetch result is immediately available, without properly waiting for it, is one of the most common beginner mistakes with this API.

Working with the Response

A typical pattern is fetch(url).then(response => response.json()).then(data => { ... use data ... }) — the response usually needs to be explicitly parsed (often as JSON) before the actual data inside it can be used.
