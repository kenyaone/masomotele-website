Variables and Data Types

Declaring Variables

let declares a variable whose value can change later; const declares one that cannot be reassigned after its initial value. Preferring const by default, using let only when a value genuinely needs to change, makes code easier to reason about.

Basic Data Types

JavaScript's core types include string (text, in quotes), number (both whole and decimal numbers), boolean (true/false), and undefined/null (representing "no value" in slightly different ways).

Type Matters for Behaviour

"5" + 3 and 5 + 3 produce different results in JavaScript (string concatenation vs numeric addition) because one operand is text and the other is a number — a common source of confusing bugs for beginners.

Key Point. JavaScript will often try to convert between types automatically rather than throwing an error — convenient, but a frequent source of subtle bugs if you are not aware it is happening.
