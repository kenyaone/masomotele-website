Domain Names and cPanel Hosting

Domain Names

A domain name (like nakuruhardwarehub.co.ke) is registered separately from where a site is actually hosted — owning the domain does not automatically mean a site is live there until it is pointed at hosting.

DNS: Connecting Domain to Host

DNS records (particularly an "A" record) tell the internet which server's IP address a domain name should resolve to — updating these records is what actually connects a purchased domain to a hosting account.

cPanel Hosting

cPanel is a widely-used web hosting control panel offering a graphical way to upload files, manage databases, and configure email for a domain — unlike GitHub Pages, this kind of hosting supports server-side languages like PHP and real databases.

Key Point. Files are typically uploaded to the public_html folder in cPanel — that folder's contents are what visitors actually see when they visit the domain.
