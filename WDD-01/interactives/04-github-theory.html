GitHub

Git vs GitHub

Git is the version-control tool itself, running locally on your computer; GitHub is an online service that hosts a copy of a Git project (a repository) — the two are related but not the same thing.

Push and Pull

git push uploads local commits to the repository on GitHub; git pull downloads any commits made elsewhere (by a teammate, or by yourself on another computer) back down to your local copy.

Why Host on GitHub

Beyond backup, GitHub gives a project a shareable public or private home — visible to collaborators or potential employers, with a browsable history of every change ever made — and is the foundation the next lesson's free hosting builds on directly.

Key Point. A GitHub profile with real, well-documented projects is itself a portfolio piece — visible evidence of actual work, not just a claim on a CV.
