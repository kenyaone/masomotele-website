# Free YouTube Videos — Digital Marketing Handbook Companion

Curated free YouTube resources mapped to every part of the MTTI *Digital Marketing Handbook (Edition 2026)*. Each section lists 2–4 videos in **recommended viewing order**. All links point to publicly available YouTube content that trainees can watch without an account. Verify each link before publishing to the LMS — YouTube URLs occasionally get removed by uploaders.

**How to use this list**
- Trainers: assign the "Primary" video as the pre-class watch; use "Deep dive" for optional revision.
- Trainees: watch the Primary videos as you read each Part of the handbook.
- LMS builders: paste the URL into your video-embed block; YouTube handles the responsive player.

## Delivery notes for the LMS builder

1. **Embed vs link.** Prefer YouTube's embed iframe over a bare link — trainees stay on the LMS page. Grab the embed code from YouTube's Share → Embed menu.
2. **Bandwidth.** For Kenyan trainees on limited data, add a "Download the notes first" callout beside every video so they can skim before playing.
3. **Ordering.** Inside each Part, the Primary video is the assigned watch. Deep-dive and long-form videos are optional revision.
4. **Verification cadence.** Re-check each URL every trimester — YouTube uploaders occasionally take videos down. If a video is gone, search for the same title; there is almost always a similar 2025/2026 replacement on the same channel.
5. **Complement, don't replace.** These videos supplement the handbook — trainees still complete the labs (Parts 8–10) and the 20-question written assessment (Part 14).
