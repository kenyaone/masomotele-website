Create a Google Sheet

📋 Google Apps Script Setup

1

Open Apps Script

In your Google Sheet, go to Extensions → Apps Script

2

Paste the Code

Delete any existing code, then paste the contents of the MTTI_CRM_AppScript.gs file (provided separately).

3

Deploy as Web App

Deploy → New Deployment → Web App

• Execute as: Me

• Who has access: Anyone

4

Copy the URL

Copy the Web App URL and paste it in the setup screen.

⚠️ Important: After any code changes, you must create a NEW deployment (not update existing) for changes to take effect.
