1. Why Pixel + CAPI (not either alone)

The Meta Pixel is a JavaScript snippet in Sarah's WordPress site. It fires client-side — from the visitor's browser. Great, until Apple's iOS 14.5 lets ~80% of iPhone users block third-party trackers with one tap.

The Conversions API (CAPI) is server-side. Sarah's server posts the same events directly to Meta over HTTPS. Ad blockers can't stop it. iOS can't block it. Combined with the Pixel, CAPI recovers 30–40% of otherwise-lost conversions.

Never run only the Pixel in 2026. Meta's optimisation collapses on iPhone-heavy audiences without CAPI. Always run both, deduplicated by a shared event_id.

3. Standard events table with EMQ bars

Click Standard events in the tab-bar above. Each of the six standard events shows a live count and its Event Match Quality bar. Learn to read the bar first, count second.

Every extra hashed parameter is worth ~0.5 EMQ. Send hashed email, phone, city, first name, last name, external ID, IP, user agent. Aim for > 8.0 on every event.

4. Test Events — pick a payload

Open the Test events tab, pick an event from the dropdown, and inspect the JSON payload Meta receives. Notice hashed PII — never send raw email or phone.

5. CAPI setup toggle

Open the Conversions API tab. Three switches — server-side sending, event deduplication, and automatic advanced matching. Turn all three ON; the estimated recovery updates in real time.

6. Kenya Data Protection Act (2019)

You can't track visitors silently in Kenya. The DPA 2019 requires informed consent before ANY personal data — including IP and browser fingerprint — is processed.

🇰🇪
Karibu Kitchen uses cookies to measure ads and personalise your visit.
By the Kenya Data Protection Act 2019 you may accept, reject, or manage below.
3 obligations under DPA 2019:
  1. Cookie banner on first visit with real Reject option.
  2. Privacy policy naming Meta as data processor and listing what's sent.
  3. Withdrawal path — visitors can un-consent later.
Break any of these and the ODPC can fine up to KES 5 million.
