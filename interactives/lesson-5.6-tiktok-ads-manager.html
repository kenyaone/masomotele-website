7. Pixel + Events API tracking

  • TikTok Pixel — JavaScript on Shopify tracks ViewContent, AddToCart, InitiateCheckout, CompletePayment
  • Events API — server-side stream directly from Shopify to TikTok (bypasses cookie blocking)
  • Shopify integration — one-click install of both
Do this BEFORE spending one shilling on ads. Untracked ads = flying blind.
