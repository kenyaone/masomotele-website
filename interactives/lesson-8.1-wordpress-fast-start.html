1. Why WordPress + Studio (60-second version)

  • WordPress = 43% of all websites. 60% of Kenyan digital marketing jobs expect it.
  • Studio = free WordPress on your laptop (by Automattic). No hosting bills. Works offline.
  • Killer feature = one-click Demo Site — a temporary public URL to show your work.
Alternatives to skip: Local WP (discontinued 2024) · XAMPP/MAMP (painful config) · Docker (advanced only).

Step 1 — Download Studio

1
Open browser → go to developer.wordpress.com/studio
2
Click the blue Download button (Windows / Mac / Linux)
3
Wait ~60 seconds. File is ~60 MB.
Only download from developer.wordpress.com. Fake sites push malware.

Step 2 — Install

1
Windows: double-click the .exe → accept license → install
2
Mac: open the .dmg → drag Studio to Applications folder
3
Linux: install the .deb or .rpm via your package manager
4
Studio appears in Start Menu / Applications

Step 3 — Create your first site

1
Launch Studio → click the big "+ Add site" card
2
Set 4 fields: Site name "Karibu Kitchen" · PHP 8.3 · WP Latest · admin auto-generated
3
Write credentials on paper NOW — losing them means starting over
4
Click Add site (10 seconds) — green dot appears when running

Step 4 — Log in to wp-admin

1
In Studio, click WP Admin on your site card
2
Login page opens in your browser
3
Enter admin username + password → Log In
4
You see the WordPress dashboard — home for the next 5 lessons
URL format: karibu-kitchen.wpstudio.local/wp-admin

Step 5 — Publish your Home page

1
In wp-admin sidebar: Pages → Add New Page
2
Type title: Home
3
Add a Cover block: search "Cover" in block picker → pick a placeholder image
4
Add H1 heading: Fresh lunch, delivered to your desk
5
Add a paragraph: Karibu Kitchen · Eldoret CBD · WhatsApp 0782 XXX XXX
6
Add a Buttons block → "Order via WhatsApp" → link to https://wa.me/254782000000
7
Click Publish — top right, blue button
8
Click View Page → your first WordPress page is live

3. wp-admin — the 3 menus you'll use daily

WordPress has 10 sidebar menus. As a marketer you'll spend 90% of your time in these three:

MenuWhat you do hereHow often
📄 PagesHome, About, Menu, Delivery, Contact — the static pages of your siteDaily during build
🎨 AppearanceTheme, colours, menus (navigation), widgets (footer)Weekly
🔌 PluginsInstall Yoast SEO, Contact Form 7, MonsterInsights (Lesson 8.7)Weekly
Ignore for now (until you need them):
  • Posts — for blog articles (come later)
  • Media — auto-managed when you upload images
  • Users, Tools, Settings — set once and forget

4. Pages vs Posts (the one critical concept)

Beginners confuse these constantly. Get it right on day one.

PagesPosts
Static contentDated entries
Fixed URL (/about)URL by date (/2026/03/…)
NOT in chronological feedChronological blog feed
Home · About · Menu · Delivery · Contact"3 recipes to try this week"
Sarah's 5 essentials in Lesson 8.5Blog articles Sarah adds later
Sarah's 5 essential pages are ALL Pages, not Posts. Build them as Posts and Google + WordPress mistreat them.
