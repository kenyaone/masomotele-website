2. Why two Karibu Kitchen sites?

Sarah runs a dev site (for experiments) and a staging site (a clone of live, for final testing before push). Neither is her live customer-facing site — that lives on HostPinnacle.

  • dev — Sarah breaks things here. Tries new plugins. Reconfigures menus. If she nukes it, no customer notices.
  • staging — A copy of the live site. Used to verify a change works before it goes live.
  • live — Only touched with Push-to-Live from Studio, or via WP-Admin on the production server.
Never edit the live site directly for anything bigger than a typo. Every real business change flows dev → staging → live.

3. Studio vs live — 3 decision scenarios

For each situation, tap where Sarah should do the work.

A. Sarah wants to try a new "menu ordering" plugin she read about on Reddit. She has no idea if it will break the checkout.

Studio — untested plugins go in dev first. If it wipes the checkout, no customer notices.

B. Sarah is redesigning the whole About page copy and layout. She wants to A/B test two versions before deciding.

Studio — big design changes get built and reviewed locally, then pushed. Live is not a scratchpad.

C. Sarah spots a typo on the live homepage — "Karibi Kitchen" instead of "Karibu Kitchen". She wants it fixed in 30 seconds.

Live — one-character typo fixes are the exception. Fix in wp-admin, save, done. Any bigger change: back to dev.

4. Studio vs LocalWP — feature match quiz

1. Who built WordPress Studio?

Correct — Automattic. Same company as WordPress.com and Jetpack.

2. Studio's killer feature that LocalWP never had?

Correct — Demo Sites let Sarah share her build with a client from her laptop with no hosting.

3. Studio runs WordPress...

Correct — a full-featured WordPress running on your machine, offline-capable.

4. LocalWP's status in 2026?

Correct — LocalWP is no longer actively maintained. Studio replaced it.

5. WordPress powers what % of the internet in 2026?

Correct — 43% and growing. It's the industry standard.

6. Reasons to build locally first?

Correct — the four practical reasons. Free, private, fast, resilient to Kenyan internet outages.
