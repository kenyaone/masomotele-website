2. Pages vs Posts

The one concept every WordPress beginner gets wrong. Learn it now or lose an hour later.

PostsPages
Time-based?Yes — dated, chronologicalNo — static
Typical URL/2026/07/friday-lunch-special//menu/
Sarah's useBlog: "This week's specials", "Meet the chef"Home, About, Menu, Delivery, Contact
Categories?Yes, plus tagsNo categories (has parent-child hierarchy)
Feed?Yes — RSSNo
Sarah's five essential pages are Pages, NOT Posts. If you accidentally build them as Posts they'll appear on the blog feed and disappear off the top-level nav.

4. Toolbar tricks Sarah uses daily

  • + New — the fastest way to create a Post, Page, Media upload, or User without leaving the current screen.
  • Updates counter — the red number is core, plugin, and theme updates waiting. Never ignore it for more than a week.
  • Howdy, Sarah — hover it to Log Out or Edit Profile.
  • Site name (top-left) — hover to hop between wp-admin and the public site.
  • Comment bubble — unread comments count. Reply promptly — unanswered comments hurt SEO signals.
Pro habit: Sarah opens wp-admin every morning, clears the updates counter, replies to comments, and shuts it. 10 minutes. Site stays healthy.
