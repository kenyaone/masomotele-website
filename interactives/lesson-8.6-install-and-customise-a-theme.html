1. What a theme controls (and doesn't)

A theme controlsA theme does NOT control
Layout (header/content/footer)Your page content
Typography (fonts + sizes)Your images (media library)
Colour paletteYour plugins
Buttons, forms, menu stylesYour database
You can install a theme, hate it, uninstall it — and no content is lost. Content and design are separate concerns. This is why WordPress is safe to experiment with.

3. Install Astra (simulated 4-step flow)

In wp-admin: Appearance → Themes → Add New Theme → search "Astra". Click the button on each step.

1
Open Appearance → Themes → Add New Theme
2
Search "Astra" — official theme by Brainstorm Force
3
Click Install (~15 seconds)
4
Click Activate
✓ Astra activated. Refresh the Karibu Kitchen homepage to see the change — cleaner header, different fonts, more space.

5. The mobile check

Click the 📱 Mobile button in the Customiser above. The preview shrinks to phone size. Check:

  • Header is still readable?
  • WhatsApp button still tappable (44 px minimum height)?
  • 3 feature tiles stack vertically instead of side by side?
  • Text doesn't overflow?
87% of Kenyan customers see the mobile view. If mobile looks broken, fix it before Publish — no exceptions.

6. Publish and go live

When it looks right, click Publish in the Customiser top bar. Changes go live instantly on the Karibu Kitchen site.

Wait — you're still local. Sarah's site is running in WordPress Studio on your laptop. Nothing is on the public internet. To share the design, click Share Demo Site in Studio — you get a temporary public URL to send to teachers, employers, or Sarah herself.
