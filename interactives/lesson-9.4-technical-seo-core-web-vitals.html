Top opportunities (biggest impact first)

Serve images in next-gen formats (WebP/AVIF) — estimated saving 1.2 s. Sarah's PNG hero is 2 MB; WebP would be ~90 KB.
Properly size images — estimated saving 0.8 s. Hero is 3,200 px wide, phones only render 900 px.
Eliminate render-blocking resources — estimated saving 0.4 s. Two theme scripts blocking first paint.
Enable text compression (gzip/brotli) — estimated saving 0.2 s. Ask host to enable.

6. sitemap.xml + robots.txt

Two files every WordPress site needs. Yoast auto-generates both.

/sitemap_index.xml
<?xml version="1.0"?>
<sitemapindex xmlns="...">
  <sitemap>
    <loc>karibukitchen.co.ke/
      page-sitemap.xml</loc>
  </sitemap>
  <sitemap>
    <loc>karibukitchen.co.ke/
      post-sitemap.xml</loc>
  </sitemap>
</sitemapindex>
/robots.txt
User-agent: *
Disallow: /wp-admin/
Allow: /wp-admin/admin-ajax.php

Sitemap: https://karibukitchen.co.ke/
  sitemap_index.xml
Do NOT touch robots.txt unless you know exactly what you're doing. Wrong entries can block Google entirely.

7. Self-check quiz

1. What are Core Web Vitals?

Correct — Largest Contentful Paint, Interaction to Next Paint, Cumulative Layout Shift.

2. LCP target?

Correct — 2.5 s or faster to hit "Good".

3. INP target?

Correct — 200 ms measures tap-to-response speed.

4. CLS target?

Correct — CLS is unitless. 0.1 or lower.

5. Which tool grades Core Web Vitals for free?

Correct — free, at pagespeed.web.dev.

6. Sarah's hero image is 2 MB PNG at 3,200 px. Biggest fix?

Correct — right format + right size drops file to ~90 KB. LCP improves 1.2 s.

7. What does robots.txt do?

Correct — crawl exclusion rules.

8. What does sitemap.xml do?

Correct — a map of the site's pages for crawlers.

9. If ONE Core Web Vital is red, what happens?

Correct — one red is enough for Google to mark the page as failing CWV.

Correct — Yoast handles both on-page SEO and sitemap generation.
