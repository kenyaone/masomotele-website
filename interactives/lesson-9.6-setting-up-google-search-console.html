1. What Search Console measures

GSC tells you five things no other tool tells you:

  1. How many people saw your site in Google results (impressions)
  2. How many clicked (clicks)
  3. Which keywords brought them (queries)
  4. Which pages are indexed (and which aren't)
  5. Technical problems Google found while crawling
GSC vs GA: Search Console shows how GOOGLE sees your site. Google Analytics shows how VISITORS behave. Both matter. Both are free. Every Kenyan marketer runs both.

2. Add a property (Domain vs URL-prefix)

Open search.google.com/search-console and click Add Property. Google offers two types:

Domain propertyURL-prefix property
Covers all variations of the domain (http, https, www, non-www, all subdomains).

Verification: DNS TXT record only. Harder for beginners.		Covers exact URL prefix (e.g. https://karibukitchen.co.ke).

Verification: HTML file, meta tag, or GA/GTM. Easier for beginners. ★
Beginner choice: URL-prefix. Type https://karibukitchen.co.ke and click Continue.

3. Verify ownership — 3 methods

Method 1: HTML file upload Medium

  1. Download the special HTML file Google gives you (e.g. google1234.html)
  2. Upload it to your site's root folder via FTP or hosting file manager
  3. Confirm it's live at karibukitchen.co.ke/google1234.html
  4. Click Verify in Search Console

Method 2: HTML tag Medium

  1. Copy the meta tag Google gives you
  2. In WordPress: Yoast SEO → General → Webmaster Tools → paste into Google verification code
  3. Click Save
  4. Click Verify in Search Console
Yoast has a dedicated field — no theme editing required.

Method 3: Google Analytics / GTM Easiest ★

  1. Ensure GA4 or Google Tag Manager is already installed on the site (Lesson 9.7 / 8.7)
  2. Sign into GSC with the SAME Google account that owns GA
  3. Google verifies automatically — no code, no upload
Use this whenever you can. Fastest, zero technical steps.

5. Submit your sitemap

After verification, the FIRST thing you do — submit the sitemap. Without it, Google might miss half your pages.

  1. Sidebar → Sitemaps
  2. Under "Add a new sitemap", type sitemap_index.xml
  3. Click Submit
  4. Wait ~24 hours. All pages appear in Google's index.
Day 1 non-negotiable: submit the sitemap. This one action can double the pages Google indexes.

7. Monday morning routine

Every Monday, 30 minutes in GSC. Four questions. Forever.

Q1. Are clicks growing?

Week-over-week clicks trending up = good. Down = action needed.

Q2. Improving in average position?

Rankings climbing means the on-page + backlink work is paying off.

Q3. Impressions but no clicks?

These queries need better titles and meta descriptions (Lesson 9.3).

Q4. Coverage or indexing errors?

Fix immediately. Every unindexed page is invisible to Google.

8. Self-check quiz

1. What does Search Console show that Google Analytics does not?

Correct — GSC is Google's view of your site; GA is the visitor's view.

2. Easiest verification method for a WordPress beginner?

Correct — no code, no file upload. GA account must be signed in with the same Google user.

3. What do you submit on day one?

Correct — sitemap first. Google needs a map to crawl every page.

4. Impressions =

Correct — appearances, not visits.

5. CTR =

Correct — the click-through rate of impressions that became clicks.

6. Sarah has 208 impressions for "food delivery Eldoret" but only 4 clicks. What does that mean?

Correct — high impressions + low CTR + high position = ranking too low to earn clicks. Improve on-page SEO.

7. If avg position is 8, where does the site rank on average?

Correct — organic results 1–10 = page 1. Position 8 is bottom of page 1.

8. Sarah's branded query "Karibu Kitchen menu" has 45.8% CTR. Why?

Correct — searchers typing "Karibu Kitchen" already want her. High CTR is expected.

9. Q3 of the Monday routine asks…

Correct — those queries are low-hanging fruit for on-page rewrites.

10. Which is a Coverage error?

Correct — Coverage tracks whether Google can access and index each URL.
