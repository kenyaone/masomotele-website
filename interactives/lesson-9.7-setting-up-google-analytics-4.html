1. What GA4 measures

Search Console showed how Google sees Sarah's site. GA4 shows how visitors behave once they arrive.

  • Who — location, device, language, first-time vs returning
  • Where they came from — Google, Facebook, direct, email, referral
  • Which pages — most viewed, entry pages, exit pages
  • How long — session duration, engagement time
  • What they did — key events (WhatsApp click, form submit, reach checkout)
Together GSC + GA4 = complete picture: GSC tells you what got them to the site, GA4 tells you what they did there.

5. Two key events every business tracks

Beyond default page views, every professional setup marks at least TWO custom events as "Key Events" (formerly called Conversions).

Event 1 — WhatsApp click

Fires every time a visitor clicks the WhatsApp CTA button.

gtag('event', 'whatsapp_click', { button_location: 'hero' });

MonsterInsights automates this — no manual code needed. Just tick "Track outbound clicks" in Enhanced Measurement.

Event 2 — form submit

Fires every time the Contact Form 7 form is submitted.

gtag('event', 'form_submit', { form_id: 'contact-form-7' });

Contact Form 7 has a built-in GA4 integration under the form settings. Tick "Send events to Google Analytics".

Then in GA4: Admin → Events → toggle "Mark as key event" for both. From that moment, every WhatsApp click and every form submit is a countable lead.

7. Self-check quiz

1. What does GA4 measure that GSC doesn't?

Correct — GA4 tracks visitors ON the site; GSC tracks how Google surfaces the site.

2. What's the correct timezone for a Kenyan property?

Correct — reports align to local time.

3. Which currency should Sarah pick?

Correct — revenue reports use the property currency.

4. Which WordPress plugin makes GA4 install a no-code job?

Correct — MonsterInsights connects and installs the tracking code automatically.

5. How do you verify GA4 is actually tracking?

Correct — Real-time is the fastest way to confirm tracking works.

6. What are Key Events (formerly)?

Correct — GA4 renamed Conversions to Key Events in 2024.

7. Which two events should Sarah track as Key Events?

Correct — these are the actions that turn a visitor into a lead.

8. Sarah's report shows 1,247 users but 84 key events. What's her conversion rate?

Correct — 84 ÷ 1,247 = 6.7%. Healthy for a Kenyan restaurant site.

9. If Real-time shows 0 users after 30 seconds while you're refreshing the site…

Correct — Real-time seeing zero means the tracking code isn't firing.
