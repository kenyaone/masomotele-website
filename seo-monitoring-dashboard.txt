DATA SOURCES & WHERE TO FIND METRICS
═══════════════════════════════════════════════════════════════════

GOOGLE SEARCH CONSOLE (search.google.com/search-console):
Location: Performance tab
→ Impressions: Shows total times your site appeared in search
→ Clicks: Total clicks from search results
→ CTR: Click-through rate (clicks ÷ impressions)
→ Position: Average ranking position in results

GOOGLE ANALYTICS (analytics.google.com):
Location: Reports → Traffic sources → Organic search
→ Sessions: Number of user sessions from organic search
→ Users: Number of unique users from organic search
→ Conversion rate: Goal completions ÷ sessions

Location: Reports → Conversions → Goals
→ Tracks all 4 conversion goals (form, WhatsApp, phone, email)

GOOGLE BUSINESS PROFILE (business.google.com):
Location: Insights tab
→ Views: How many times people viewed your listing
→ Calls: Phone inquiries from your listing
→ Website Clicks: Clicks from your listing to your website
→ Directions: How many requested directions to your location

RED FLAGS: When to Escalate & Optimize
═══════════════════════════════════════════════════════════════════

⚠️ RED FLAG: Organic traffic declining
   → Action: Check Google Search Console for penalties/errors
   → Action: Review recent page changes
   → Action: Check competitor keywords

⚠️ RED FLAG: High impressions but low CTR (<2%)
   → Action: Improve page titles and meta descriptions
   → Action: Add rich snippets/schema markup
   → Action: A/B test different titles

⚠️ RED FLAG: Traffic but no conversions (conversion rate <1%)
   → Action: Review CTA buttons and forms
   → Action: Check form for friction points
   → Action: Test landing page design changes

⚠️ RED FLAG: Rankings dropping significantly
   → Action: Check for technical SEO issues
   → Action: Review content freshness
   → Action: Compare to competitor content

⚠️ RED FLAG: Backlinks decreasing
   → Action: Check for link rot (old pages deleted)
   → Action: Accelerate new backlink acquisition
   → Action: Reach out to previous link sources
