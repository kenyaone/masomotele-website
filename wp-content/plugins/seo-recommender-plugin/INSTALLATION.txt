SEO RECOMMENDER PLUGIN - INSTALLATION GUIDE
============================================

STEP 1: UPLOAD THE PLUGIN
------------------------
Method A (Via FTP):
1. Connect to your website via FTP
2. Navigate to: /wp-content/plugins/
3. Upload the entire "seo-recommender-plugin" folder

Method B (Via WordPress Admin):
1. Go to: WordPress Admin Dashboard
2. Navigate to: Plugins → Add New
3. Click "Upload Plugin"
4. Select the plugin folder
5. Click "Install Now"

STEP 2: ACTIVATE THE PLUGIN
---------------------------
1. Go to: Plugins in WordPress Admin
2. Find: "SEO Recommender"
3. Click: "Activate"

STEP 3: VERIFY INSTALLATION
---------------------------
1. Look for "SEO Recommender" in the left sidebar
2. You should see menu items:
   - Dashboard
   - Analyze Content
   - Settings

STEP 4: (OPTIONAL) CONFIGURE SETTINGS
-------------------------------------
1. Click: SEO Recommender → Settings
2. Adjust minimum content lengths if needed
3. Click: Save Changes

STEP 5: START ANALYZING
-----------------------
1. Click: SEO Recommender → Analyze Content
2. Select a post or page
3. Click: Analyze
4. View recommendations

TROUBLESHOOTING
===============

Plugin not showing in sidebar?
- Clear your browser cache
- Log out and back in
- Try different browser

Recommendations not loading?
- Check WordPress version (4.0+)
- Verify plugin is activated
- Check browser console (F12) for errors

Need help?
- Check README.md for more info
- Review plugin comments
- Contact support

UNINSTALLATION
==============
1. Go to: Plugins
2. Find: "SEO Recommender"
3. Click: Deactivate
4. Click: Delete
5. Confirm deletion
