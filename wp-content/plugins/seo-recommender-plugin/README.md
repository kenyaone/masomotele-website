# SEO Recommender WordPress Plugin

A powerful WordPress plugin that analyzes your content and provides actionable SEO recommendations.

## Features

✅ **Content Analysis** - Analyzes posts and pages for SEO optimization
✅ **SEO Score** - Calculates an overall SEO score (0-100%)
✅ **Smart Recommendations** - Provides specific, actionable recommendations
✅ **Dashboard** - View analytics about your site's SEO health
✅ **Post Analysis** - Inline analysis directly in post editor
✅ **Bulk Analysis** - Analyze multiple posts quickly
✅ **Settings** - Customize SEO criteria to your needs

## What It Checks

The plugin analyzes content for:

- **Title Length** - Recommends 50-60 characters
- **Meta Description** - Checks for 120-160 character descriptions
- **Content Length** - Ensures adequate content (300+ words)
- **H1 Tags** - Verifies H1 header exists
- **Internal Links** - Checks for relevant internal linking
- **Images** - Recommends images for better engagement
- **Image Alt Text** - Ensures images have alt text
- **URL Slugs** - Validates URL structure
- **Keyword Density** - Analyzes keyword usage

## Installation

1. **Upload Plugin**
   - Download the `seo-recommender-plugin` folder
   - Upload to `/wp-content/plugins/` via FTP or WordPress admin
   
2. **Activate Plugin**
   - Go to WordPress Admin → Plugins
   - Find "SEO Recommender"
   - Click "Activate"

3. **Configure Settings** (Optional)
   - Go to SEO Recommender → Settings
   - Adjust minimum content lengths and criteria as needed

## How to Use

### Dashboard
- **SEO Recommender → Dashboard**
- View overall SEO health
- See recent posts analysis
- Check optimization statistics

### Analyze Content
- **SEO Recommender → Analyze Content**
- Select a post or page
- Click "Analyze"
- View detailed recommendations

### Post Editor
- **When editing a post/page**
- See SEO score in right sidebar
- Check recommendations in meta box
- Real-time analysis as you write

### Columns View
- **Posts/Pages list view**
- See SEO score for each post
- Green = well optimized (70%+)
- Orange = needs work (50-69%)
- Red = needs significant improvement (<50%)

## Recommendations Explained

### ❌ Critical Issues (Most Important)
- Missing meta description
- Missing H1 tag
- These significantly impact search rankings

### ⚠️ Warnings (Important)
- Short content
- Short title
- No internal links
- Missing image alt text
- Focus on these to improve rankings

### ℹ️ Tips (Helpful)
- No images
- Low keyword density
- URL structure issues
- These help but are less critical

## Example Recommendations

**Short Title**
- Issue: Title is less than 30 characters
- Fix: Expand title to 50-60 characters including keywords
- Example: "Best SEO Tips" → "Best SEO Tips for WordPress Blogs in 2024"

**Missing Meta Description**
- Issue: No meta description found
- Fix: Add 120-160 character description
- Example: "Learn proven SEO strategies to improve your WordPress site's visibility in search engines and drive more organic traffic."

**No Internal Links**
- Issue: No links to other content
- Fix: Add 2-3 relevant internal links
- Why: Helps Google understand site structure and keeps readers engaged

## Settings

Go to **SEO Recommender → Settings** to adjust:

- **Minimum Title Length** - Default: 30 characters
- **Minimum Meta Description Length** - Default: 120 characters  
- **Minimum Content Length** - Default: 300 words

## FAQs

**Q: Will this conflict with other SEO plugins?**
A: No, it works alongside other plugins and doesn't modify content.

**Q: What's a good SEO score?**
A: 70%+ is excellent, 50-70% is good, below 50% needs work.

**Q: Can I ignore some recommendations?**
A: Yes, but critical issues (❌) should be addressed for best results.

**Q: Does it monitor rankings?**
A: No, it only analyzes on-page SEO. For rankings, use Google Search Console.

**Q: Can I export recommendations?**
A: Currently not, but you can copy-paste from the analysis.

## Tips for Best Results

1. **Aim for 70%+ Score** - This indicates well-optimized content
2. **Address Critical Issues First** - These have biggest impact
3. **Write Naturally** - Don't force keywords unnaturally
4. **Use Proper Headers** - H1, H2, H3 tags help structure
5. **Add Images** - Break up text and improve engagement
6. **Link Internally** - Help readers find related content
7. **Write Longer Content** - 1000+ words often ranks better

## Troubleshooting

**No recommendations showing?**
- Clear browser cache
- Refresh the page
- Check browser console for errors

**Plugin not appearing?**
- Verify it's activated in Plugins menu
- Check WordPress version (requires 4.0+)

**Recommendations not accurate?**
- Update plugin to latest version
- Go to Settings and verify criteria
- Manually analyze post again
